§1 Соответствие элементов в равных треугольниках

Определение. Два треугольника называются равными, если их можно совместить наложением. При этом все соответствующие стороны и углы равны.

Если \(\triangle ABC = \triangle A_1B_1C_1\), то порядок букв в записи равенства задаёт соответствие вершин:

\(A \leftrightarrow A_1, \quad B \leftrightarrow B_1, \quad C \leftrightarrow C_1\)

Из этого соответствия автоматически следуют равенства сторон и углов:

\(AB = A_1B_1, \quad BC = B_1C_1, \quad CA = C_1A_1\)
\(\angle A = \angle A_1, \quad \angle B = \angle B_1, \quad \angle C = \angle C_1\)
Важно! Если в задаче дано \(\triangle ABC = \triangle A_1B_1C_1\), то нельзя произвольно переставлять буквы. Например, сторона \(AB\) соответствует стороне \(A_1B_1\), а не \(B_1C_1\).
\(\triangle ABC = \triangle A_1B_1C_1\)
Пример 1. Дано \(\triangle ABC = \triangle A_1B_1C_1\), причём \(\angle A = 50^\circ\), \(\angle B = 70^\circ\), \(AB = 6\) см. Найти \(\angle A_1\), \(\angle B_1\), \(A_1B_1\).
По определению равных треугольников:
\(\angle A_1 = \angle A = 50^\circ\)
\(\angle B_1 = \angle B = 70^\circ\)
\(A_1B_1 = AB = 6\) см
Ответ: \(\angle A_1 = 50^\circ\), \(\angle B_1 = 70^\circ\), \(A_1B_1 = 6\) см.
Пример 2. Дано \(\triangle MKL = \triangle M_1K_1L_1\), причём \(MK = 12\) см, \(KL = 9\) см, \(\angle L = 55^\circ\). Найти \(M_1K_1\), \(K_1L_1\), \(\angle L_1\).
\(M_1K_1 = MK = 12\) см
\(K_1L_1 = KL = 9\) см
\(\angle L_1 = \angle L = 55^\circ\)
Ответ: \(M_1K_1 = 12\) см, \(K_1L_1 = 9\) см, \(\angle L_1 = 55^\circ\).

§2 Решение уравнений со скобками

При решении уравнений со скобками важно правильно раскрывать скобки и переносить слагаемые.

Правила раскрытия скобок:
  • Если перед скобкой стоит знак «+», знаки внутри не меняются.
  • Если перед скобкой стоит знак «−», знаки всех слагаемых внутри меняются на противоположные.
  • Если перед скобкой стоит число, умножаем его на каждое слагаемое в скобках.
Правило переноса. При переносе слагаемого из одной части уравнения в другую его знак меняется на противоположный.
\(5x + (3x - 3) = 6x + 11\)
Пример 1. Решить уравнение \(5x + (3x - 3) = 6x + 11\).
Раскроем скобки: \(5x + 3x - 3 = 6x + 11\)
Перенесём слагаемые с \(x\) влево, числа вправо: \(5x + 3x - 6x = 11 + 3\)
Приведём подобные: \(2x = 14\)
Разделим на 2: \(x = 7\)
Ответ: \(7\).
Пример 2. Решить уравнение \(3a - (10 + 5a) = 54\).
Раскроем скобки: \(3a - 10 - 5a = 54\)
Приведём подобные: \(-2a - 10 = 54\)
Перенесём число: \(-2a = 54 + 10\)
\(-2a = 64\)
Разделим на \(-2\): \(a = -32\)
Ответ: \(-32\).
Пример 3. Решить уравнение \((x - 7) - (2x + 9) = -13\).
Раскроем скобки: \(x - 7 - 2x - 9 = -13\)
Приведём подобные: \(-x - 16 = -13\)
Перенесём число: \(-x = -13 + 16\)
\(-x = 3\)
Умножим на \(-1\): \(x = -3\)
Ответ: \(-3\).
Пример 4. Решить уравнение \(0{,}6 + (0{,}5y - 1) = y + 0{,}5\).
Раскроем скобки: \(0{,}6 + 0{,}5y - 1 = y + 0{,}5\)
Приведём подобные в левой части: \(0{,}5y - 0{,}4 = y + 0{,}5\)
Перенесём слагаемые с \(y\) влево, числа вправо: \(0{,}5y - y = 0{,}5 + 0{,}4\)
\(-0{,}5y = 0{,}9\)
Разделим на \(-0{,}5\): \(y = -1{,}8\)
Ответ: \(-1{,}8\).

§3 Составление уравнения по условию задачи

Часто в задачах требуется найти значение переменной, при котором выражения равны или одно больше другого. Для этого составляют уравнение.

Ключевые фразы:
  • «значения выражений равны» → приравниваем выражения.
  • «значение выражения \(A\) на \(k\) больше значения выражения \(B\)» → \(A - B = k\).
  • «значение выражения \(A\) в \(k\) раз больше значения выражения \(B\)» → \(A = k \cdot B\).
  • «значение выражения \(A\) на \(k\) меньше значения выражения \(B\)» → \(B - A = k\).
  • «значение выражения \(A\) в \(k\) раз меньше значения выражения \(B\)» → \(B = k \cdot A\).
Пример 1. При каком значении \(m\) значения выражений \(2m - 13\) и \(m + 3\) равны?
Составим уравнение: \(2m - 13 = m + 3\)
\(2m - m = 3 + 13\)
\(m = 16\)
Ответ: \(m = 16\).
Пример 2. При каком значении \(c\) значение выражения \(3 - 5c\) на 1 меньше значения выражения \(1 - c\)?
«На 1 меньше» означает: \((1 - c) - (3 - 5c) = 1\)
\(1 - c - 3 + 5c = 1\)
\(4c - 2 = 1\)
\(4c = 3\)
\(c = 0{,}75\)
Ответ: \(c = 0{,}75\).
Пример 3. При каком значении \(x\) значение выражения \(2x + 1\) на 20 больше значения выражения \(8x + 5\)?
\((2x + 1) - (8x + 5) = 20\)
\(2x + 1 - 8x - 5 = 20\)
\(-6x - 4 = 20\)
\(-6x = 24\)
\(x = -4\)
Ответ: \(x = -4\).
Пример 4. При каком значении \(x\) значение \(x\) в 3 раза меньше значения выражения \(45 - 10x\)?
«В 3 раза меньше» означает: \(45 - 10x = 3x\)
\(45 = 3x + 10x\)
\(45 = 13x\)
\(x = \dfrac{45}{13}\)
Ответ: \(x = \dfrac{45}{13}\).
Пример 5. При каком значении \(y\) значение выражения \(9 - y\) в 2 раза больше значения \(y\)?
\(9 - y = 2y\)
\(9 = 3y\)
\(y = 3\)
Ответ: \(y = 3\).
