Раскрытие скобок
1. Плюс перед скобкой
Правило
Если перед скобкой стоит знак «+», скобки можно просто опустить — знаки слагаемых не меняются.
\(a + (b - c + d) = a + b - c + d\)
Пример: \(x + (a + b - c) = x + a + b - c\)
✅ Как запомнить

Плюс перед скобкой — «добрый знак». Все знаки внутри остаются такими же.

2. Минус перед скобкой
Правило
Если перед скобкой стоит знак «−», при раскрытии скобок знаки всех слагаемых меняются на противоположные.
\(a - (b - c + d) = a - b + c - d\)
Пример: \(m - (n - k - p) = m - n + k + p\)
⚠️ Частая ошибка

Минус перед скобкой меняет знак каждого слагаемого внутри. Нельзя поменять только у первого!

3. Число перед скобкой
Распределительное свойство
Чтобы умножить число на сумму, нужно умножить это число на каждое слагаемое и результаты сложить.
\(k(b + c) = kb + kc\)
\(k(b - c) = kb - kc\)
Пример: \(3(2x - 5) = 3 \cdot 2x - 3 \cdot 5 = 6x - 15\)
✅ С минусом перед числом

Если число отрицательное, умножаем на него каждое слагаемое, следя за знаками:

\(-2(3 - x) = -2 \cdot 3 + 2 \cdot x = -6 + 2x\)

Подобные слагаемые
4. Что такое подобные слагаемые
Определение
Подобные слагаемые — это слагаемые, у которых одинаковая буквенная часть.

Например, в выражении \(3x + 5x - 2y\) слагаемые \(3x\) и \(5x\) — подобные (буквенная часть \(x\)), а \(-2y\) — не подобно им.

⚠️ Коэффициент

Число перед буквой называется коэффициентом. Если числа нет, коэффициент равен 1 или −1:

\(x = 1x \qquad -x = -1x\)
5. Как приводить подобные
⚠️ Алгоритм
  1. Сложить коэффициенты подобных слагаемых.
  2. Умножить полученное число на общую буквенную часть.
\(3x + 5x = (3 + 5)x = 8x\)
Пример: Упростим \(7a - 2a + 4b - b\)
\(7a - 2a = 5a\) (подобные с буквой \(a\))
\(4b - b = 3b\) (подобные с буквой \(b\))
Ответ: \(5a + 3b\)
✅ Числа без буквы

Слагаемые без буквенной части тоже приводятся между собой:

\(3 + 5 - 2 = 6\)
⚠️ Частая ошибка

Нельзя складывать слагаемые с разной буквенной частью! \(3x + 5y \neq 8xy\)

Сложные случаи
6. Дробные коэффициенты
📌 Как действовать

Умножаем дробь на каждое слагаемое. Дробь умножается на число обычным способом:

\(\frac{1}{2}(4x - 6) = \frac{1}{2} \cdot 4x - \frac{1}{2} \cdot 6 = 2x - 3\)
Пример: \(0{,}5(2y - 8) = 1y - 4 = y - 4\)
7. Несколько скобок подряд
⚠️ Порядок действий
  1. Раскрываем первую скобку.
  2. Раскрываем вторую скобку.
  3. Приводим подобные.
Пример: \(12 + 7x - (1 - 3x)\)
Раскрываем скобку с минусом: \(12 + 7x - 1 + 3x\)
Приводим подобные: \(7x + 3x + 12 - 1 = 10x + 11\)
8. Нахождение значения выражения
✅ Порядок действий
  1. Упростить выражение.
  2. Подставить значение переменной.
  3. Вычислить результат.
Пример: Упростим и найдём значение \((2x - 3) - (5 - 4x)\) при \(x = 0{,}5\)
Упрощаем: \(2x - 3 - 5 + 4x = 6x - 8\)
Подставляем: \(6 \cdot 0{,}5 - 8 = 3 - 8 = -5\)
💡 Совет

Сначала упрощай, потом подставляй — так вычислять проще и меньше ошибок.

📌
Итоговый алгоритм
Как упрощать выражения
  1. Раскрыть скобки — учитывая знак перед ними.
  2. Перемножить числа — если есть произведение.
  3. Привести подобные слагаемые — сложить коэффициенты с одинаковой буквенной частью.
  4. Записать ответ — в стандартном виде.
✅ Запомни

Тождественные преобразования не меняют значение выражения — они только упрощают его запись.
