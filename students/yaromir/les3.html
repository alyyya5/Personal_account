§1 Что такое корень n-й степени?

Определение. Арифметическим корнем \(n\)-й степени из числа \(a\) называется такое неотрицательное число \(b\), которое при возведении в степень \(n\) даёт \(a\).
Записывается как: \(a^{\frac{1}{n}} = b\), где \(b \ge 0\) и \(b^n = a\).
Важно помнить:
  • Корень чётной степени (\(n=2, 4, 6\dots\)) можно извлекать только из неотрицательных чисел (\(a \ge 0\)).
  • Корень нечётной степени (\(n=3, 5, 7\dots\)) можно извлекать из любых действительных чисел.
  • Результат арифметического корня всегда неотрицателен.

§2 Основные свойства степеней

Для упрощения выражений используются следующие правила действий со степенями:

1. Умножение степеней с одинаковым основанием:
\(a^x \cdot a^y = a^{x+y}\)
2. Деление степеней с одинаковым основанием:
\(\frac{a^x}{a^y} = a^{x-y}\)
3. Возведение степени в степень:
\((a^x)^y = a^{x \cdot y}\)
4. Степень произведения:
\((a \cdot b)^x = a^x \cdot b^x\)
5. Степень частного:
\(\left(\frac{a}{b}\right)^x = \frac{a^x}{b^x}\)
Связь корней и степеней:
Корень \(n\)-й степени — это то же самое, что степень \(\frac{1}{n}\).
Например: \(a^{\frac{m}{n}} = (a^{\frac{1}{n}})^m\). Это позволяет применять все правила степеней к корням.

§3 Алгоритм упрощения

Пример 1 (Умножение):
Упростить: \(8^{\frac{1}{3}} \cdot 4^{\frac{1}{2}}\)
Приведём основания к степеням двойки:
\(8 = 2^3\), значит \(8^{\frac{1}{3}} = (2^3)^{\frac{1}{3}} = 2^1 = 2\).
\(4 = 2^2\), значит \(4^{\frac{1}{2}} = (2^2)^{\frac{1}{2}} = 2^1 = 2\).
Результат: \(2 \cdot 2 = 4\).
Пример 2 (Деление и вычитание показателей):
Упростить: \(\frac{x^{\frac{5}{6}}}{x^{\frac{1}{3}}}\)
При делении показатели вычитаются:
\(\frac{5}{6} - \frac{1}{3} = \frac{5}{6} - \frac{2}{6} = \frac{3}{6} = \frac{1}{2}\).
Ответ: \(x^{\frac{1}{2}}\).
Пример 3 (Сложная степень):
Вычислить: \((27^{\frac{1}{3}})^2\)
Сначала извлекаем кубический корень из 27: \(27^{\frac{1}{3}} = 3\).
Затем возводим результат в квадрат: \(3^2 = 9\).

§4 Типичные ошибки

Внимание! Часто ученики путают сложение оснований и сложение показателей.

❌ НЕВЕРНО: \(2^3 + 2^4 = 2^7\) (так делать нельзя!).
✅ ВЕРНО: \(2^3 + 2^4 = 8 + 16 = 24\).

Правила сложения/вычитания показателей работают только при умножении или делении степеней.
