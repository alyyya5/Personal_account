Положительные и отрицательные числа

Модуль · Сложение и вычитание

1. Координатная прямая

Прямая, на которой выбраны начало отсчёта (0), положительное направление и единичный отрезок, называется координатной прямой.

На координатной прямой числа слева от нуля — отрицательные, справа — положительные.
  • Справа от нуля — положительные числа.
  • Слева от нуля — отрицательные числа.
Примеры: 5, 7, 0.3 — положительные; –2, –0.7, –3/4 — отрицательные.

2. Противоположные числа

Числа, которые отличаются только знаком, называются противоположными.

Пример: 7 и –7; –2.5 и 2.5
  • Ноль противоположен сам себе.
  • На координатной прямой противоположные числа расположены симметрично относительно нуля.
Если число a, то противоположное ему — –a.

3. Модуль числа

Модуль — это расстояние от начала отсчёта до точки с данной координатой.

Обозначение: |n|
  • Модуль всегда неотрицателен: |n| ≥ 0.
  • Для положительных чисел и нуля: |n| = n.
  • Для отрицательных чисел: |n| = –n (например, |–7| = 7).
Свойство: модули противоположных чисел равны: |–a| = |a|.
Примеры: |–7| = 7, |3.5| = 3.5, |0| = 0

4. Сравнение чисел

  • Любое положительное число больше любого отрицательного.
  • Ноль больше отрицательного, но меньше положительного.
  • Из двух отрицательных чисел больше то, у которого модуль меньше.
Пример: –5 < –3 (так как |–5|=5, |–3|=3, 5>3 → –5<–3)
На координатной прямой большее число всегда находится правее.

5. Сложение и вычитание

Сложение двух отрицательных

сложить модули, поставить знак «–»
Пример: –3 + (–5) = –8

Сложение чисел с разными знаками

из большего модуля вычесть меньший, поставить знак числа с большим модулем
Примеры: –7 + 4 = –3; 8 + (–5) = 3

Вычитание

a – b = a + (–b)
Примеры: 8 – (–3) = 11; –5 – (–7) = 2

Свойства сложения

  • Переместительное: a + b = b + a
  • Сочетательное: (a + b) + c = a + (b + c)
  • Сумма противоположных чисел: a + (–a) = 0

6. Длина отрезка

Длина = |x₂ – x₁|
Пример: между точками M(–5) и N(3): |3 – (–5)| = 8
Длина отрезка всегда положительное число.
