§1 Вертикальные и смежные углы

Определение. Два угла называются вертикальными, если стороны одного угла являются продолжениями сторон другого.
Определение. Два угла называются смежными, если у них одна сторона общая, а две другие стороны являются продолжениями одна другой.
Пересекающиеся прямые \(PM\) и \(KL\)
Свойства:
  • Вертикальные углы равны: \(\angle PBK = \angle MBL\), \(\angle PBL = \angle MBK\).
  • Сумма смежных углов равна \(180^\circ\): \(\angle PBK + \angle PBL = 180^\circ\).
Виды углов:
  • Острый — меньше \(90^\circ\).
  • Прямой — равен \(90^\circ\).
  • Тупой — больше \(90^\circ\), но меньше \(180^\circ\).
  • Развёрнутый — равен \(180^\circ\).
Пример. На рисунке \(\angle MBK = 65^\circ\). Найдём остальные углы.
\(\angle MBK = 65^\circ\) — острый (меньше \(90^\circ\))
\(\angle PBL = \angle MBK = 65^\circ\) — вертикальные
\(\angle PBK = 180^\circ - 65^\circ = 115^\circ\) — смежный с \(\angle MBK\), тупой
\(\angle MBL = \angle PBK = 115^\circ\) — вертикальные

§2 Биссектриса угла

Определение. Биссектрисой угла называется луч, исходящий из вершины угла и делящий его на два равных угла.
\(MA\) — биссектриса угла \(\angle KML\)
Если \(MA\) — биссектриса \(\angle KML\), то
\(\angle KMA = \angle AML = \frac{1}{2}\angle KML\)
Пример. \(\angle KML = 126^\circ\), \(MA\) — биссектриса. Найти \(\angle AML\).
\(\angle AML = 126^\circ : 2 = 63^\circ\)
Ответ: \(63^\circ\).

§3 Части отрезка

Если точка делит отрезок на две части, то длина всего отрезка равна сумме длин его частей.

Отрезок \(DF\), разделённый точкой \(C\)
\(DF = DC + CF\)
Пример. \(DF = 28\) см, \(CF\) в 3 раза больше \(DC\). Найти \(DC\) и \(CF\).
Пусть \(DC = x\), тогда \(CF = 3x\).
\(x + 3x = 28\)
\(4x = 28\)
\(x = 7\)
Значит, \(DC = 7\) см, \(CF = 3 \cdot 7 = 21\) см.
Ответ: \(DC = 7\) см, \(CF = 21\) см.

§4 Углы с общей вершиной

Если из одной точки выходят несколько лучей, то больший угол можно представить как сумму или разность меньших углов.

Лучи \(MO\), \(MK\), \(MN\) с общей вершиной \(M\)
Возможны два случая:
  • Луч \(MK\) лежит внутри угла \(\angle OMN\): тогда \(\angle OMN = \angle OMK + \angle KMN\).
  • Луч \(MK\) лежит вне угла \(\angle OMN\): тогда \(\angle NMK = \angle OMN + \angle OMK\).
Пример (луч внутри). \(\angle OMN = 84^\circ\), \(\angle OMK = 25^\circ\). Найти \(\angle NMK\).
\(\angle NMK = \angle OMN - \angle OMK = 84^\circ - 25^\circ = 59^\circ\)
Ответ: \(59^\circ\).
Пример (луч вне). \(\angle OMN = 84^\circ\), \(\angle OMK = 25^\circ\). Найти \(\angle NMK\).
\(\angle NMK = \angle OMN + \angle OMK = 84^\circ + 25^\circ = 109^\circ\)
Ответ: \(109^\circ\).

§5 Решение уравнений со скобками

При решении уравнений со скобками важно правильно раскрывать скобки и переносить слагаемые.

Правила раскрытия скобок:
  • Если перед скобкой стоит знак «+», знаки внутри не меняются.
  • Если перед скобкой стоит знак «−», знаки всех слагаемых внутри меняются на противоположные.
  • Если перед скобкой стоит число, умножаем его на каждое слагаемое в скобках.
Правило переноса. При переносе слагаемого из одной части уравнения в другую его знак меняется на противоположный.
\(4(x + 3) = 2(x + 10)\)
Пример 1. Решить уравнение \(4(x + 3) = 2(x + 10)\).
Раскроем скобки: \(4x + 12 = 2x + 20\)
Перенесём слагаемые с \(x\) влево, числа вправо: \(4x - 2x = 20 - 12\)
Приведём подобные: \(2x = 8\)
Разделим на 2: \(x = 4\)
Ответ: \(4\).
Пример 2. Решить уравнение \(3(2y - 1) = 5y + 7\).
Раскроем скобки: \(6y - 3 = 5y + 7\)
Перенесём: \(6y - 5y = 7 + 3\)
Приведём подобные: \(y = 10\)
Ответ: \(10\).
Пример 3. Решить уравнение \(7 - 2(3x + 1) = 5x - 9\).
Раскроем скобки: \(7 - 6x - 2 = 5x - 9\)
Приведём подобные в левой части: \(5 - 6x = 5x - 9\)
Перенесём слагаемые с \(x\) влево, числа вправо: \(-6x - 5x = -9 - 5\)
\(-11x = -14\)
Разделим на \(-11\): \(x = \dfrac{14}{11}\)
Ответ: \(\dfrac{14}{11}\).
