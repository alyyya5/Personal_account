§1 Что такое числовой промежуток

Пусть \(a < b\) — два числа. Множество чисел, удовлетворяющих неравенству \(a < x < b\), называется интервалом и обозначается \((a; b)\). Точки \(a\) и \(b\) этому промежутку не принадлежат.

Интервал \((a; b)\):
\(a < x < b\)
Точки \(a\) и \(b\) — выколоты (не входят).

Множество чисел \(x\), для которых выполняются неравенства \(a \le x \le b\), называется отрезком и обозначается \([a; b]\). Точки \(a\) и \(b\) этому промежутку принадлежат.

Отрезок \([a; b]\):
\(a \le x \le b\)
Точки \(a\) и \(b\) — закрашены (входят).

Если один конец входит, а другой нет — это полуинтервал:

Полуинтервалы:
\([a; b)\) — \(a \le x < b\) (закрашен \(a\), выколот \(b\))
\((a; b]\) — \(a < x \le b\) (выколот \(a\), закрашен \(b\))
Бесконечные промежутки:
\((-\infty; a)\) — \(x < a\)
\((-\infty; a]\) — \(x \le a\)
\((a; +\infty)\) — \(x > a\)
\([a; +\infty)\) — \(x \ge a\)
\((-\infty; +\infty)\) — все действительные числа.

§2 Как рисовать промежутки на прямой

Правила изображения:
  • Если знак \(<\) или \(>\) — точка выколотая (кружок не закрашен).
  • Если знак \(\le\) или \(\ge\) — точка закрашенная.
  • Штриховка показывает, какие числа входят в промежуток.
Пример 1. Изобразим промежуток \(x > 2\).
Ставим выколотую точку \(2\), штрихуем вправо.
Этот промежуток называется лучом и обозначается \((2; +\infty)\).
Пример 2. \(x \le 3\).
Ставим закрашенную точку \(3\), штрихуем влево.
Обозначение: \((-\infty; 3]\).

§3 Расстояние между точками координатной прямой

Пусть на координатной прямой даны точки \(A(a)\) и \(B(b)\). Расстояние между ними равно модулю разности их координат:

\(AB = |a - b|\)

Почему модуль? Если \(b > a\), расстояние равно \(b - a\) (положительное). Если \(b < a\), расстояние равно \(a - b\) (тоже положительное). В обоих случаях — модуль разности.

Пример 1. \(A(3)\), \(B(8)\).
\(AB = |3 - 8| = |-5| = 5\).
Пример 2. \(M(-4)\), \(N(2)\).
\(MN = |-4 - 2| = |-6| = 6\).
Середина отрезка. Если \(M\) — середина \(AB\), то \(AM = MB = \dfrac{AB}{2}\). Координата середины: \(\dfrac{a + b}{2}\).

§4 Что такое функция

Определение. Функцией называется правило, по которому каждому значению одной переменной соответствует ровно одно значение другой переменной.

Проще говоря, функция — это «машина», которая берёт число, что-то с ним делает по определённому правилу и выдаёт результат.

Пример из жизни: автомат по продаже кофе. Вы опускаете монету (вход), нажимаете кнопку, и получаете чашку кофе (выход). Каждой монете соответствует ровно один стакан кофе.

§5 Независимая и зависимая переменные

В функции всегда участвуют две переменные. Важно уметь их различать.

Независимая переменная (аргумент) — это переменная, которую мы задаём сами. Обычно обозначается буквой \(x\). От неё зависит результат.
Зависимая переменная (функция) — это переменная, значение которой вычисляется по правилу. Обычно обозначается буквой \(y\). Её значение зависит от \(x\).
Схема:
\(x\) (аргумент) \(\longrightarrow\) правило \(\longrightarrow\) \(y\) (функция)
Как запомнить: аргумент — это то, что мы «крутим» (независимая переменная), а функция — это то, что получается в результате (зависимая переменная).

§6 Как составить формулу функции

Формула функции — это математическая запись правила, по которому вычисляется зависимая переменная.

  1. Выберите независимую переменную (аргумент). Подумайте, какое значение вы задаёте сами, чтобы узнать результат.
  2. Запишите правило. Вспомните формулу, которая связывает эту величину с результатом (например, площадь, периметр, расстояние).
  3. Проверьте. Убедитесь, что каждому \(x\) соответствует только одно значение \(y\).
Пример 1. Периметр квадрата зависит от его стороны \(a\).
Независимая переменная: \(a\) (сторона квадрата).
Зависимая переменная: \(P\) (периметр).
Формула: \(P = 4a\).
Пример 2. Площадь прямоугольника со сторонами \(9\) см и \(x\) см.
Независимая переменная: \(x\) (вторая сторона).
Зависимая переменная: \(S\) (площадь).
Формула: \(S = 9x\).

§7 Как найти значение функции

Чтобы найти значение функции, нужно подставить заданное значение аргумента в формулу и выполнить вычисления.

Если \(y = f(x)\), то значение функции при \(x = a\) — это \(f(a)\).
Пример 1. Дана функция \(P = 4a\). Найти периметр при \(a = 3\).
Подставим \(a = 3\) в формулу:
\(P = 4 \cdot 3 = 12\).
Ответ: \(12\).
Пример 2. Дана функция \(s = 70t\) (расстояние поезда). Найти путь при \(t = 2\), \(t = 4\), \(t = 3{,}8\).
\(t = 2\): \(s = 70 \cdot 2 = 140\) км.
\(t = 4\): \(s = 70 \cdot 4 = 280\) км.
\(t = 3{,}8\): \(s = 70 \cdot 3{,}8 = 266\) км.
Совет: если нужно найти значение аргумента по известному значению функции (обратная задача), подставьте известное \(y\) в формулу и решите полученное уравнение относительно \(x\).
