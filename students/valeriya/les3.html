Решение уравнений

Теория для подготовки

1. Уравнение

Уравнение — это равенство, содержащее неизвестное число, которое нужно найти.

Неизвестное обычно обозначают буквой x.

Пример: 2x + 3 = 7

Корень уравнения — это значение неизвестного, при котором уравнение становится верным числовым равенством.

2. Свойства равенств

Равенство можно преобразовывать. Главное — делать это с обеими частями одновременно.

Свойство 1. Прибавление и вычитание: Если a = b, то a + c = b + c Если a = b, то a – c = b – c (можно прибавить или вычесть одно и то же число) Свойство 2. Умножение и деление: Если a = b, то a · c = b · c Если a = b, то a : c = b : c (c ≠ 0) (можно умножить или разделить на одно и то же число)
Пример: 2x + 3 = 7
Вычтем 3 из обеих частей: 2x + 3 – 3 = 7 – 3 → 2x = 4
Разделим обе части на 2: 2x : 2 = 4 : 2 → x = 2
Важно: если разделить или умножить на отрицательное число, знак неравенства поменяется (это для неравенств, а в уравнениях знак «=» просто остаётся).

3. Перенос слагаемых

Из свойства равенств (прибавление и вычитание) следует правило переноса:

Правило: Любое слагаемое можно перенести из одной части уравнения в другую, поменяв его знак на противоположный.
Пример: 2x + 3 = 7
Переносим 3 вправо с противоположным знаком: 2x = 7 – 3 → 2x = 4
Пример с буквами: 5x – 2 = 3x + 8
Переносим 3x влево: 5x – 3x – 2 = 8 → 2x – 2 = 8
Переносим –2 вправо: 2x = 8 + 2 → 2x = 10
Запомните: при переносе меняется только знак самого слагаемого!

4. Приведение подобных

Подобные слагаемые — это слагаемые с одинаковой буквенной частью.

Правило: Чтобы привести подобные, нужно сложить их коэффициенты, а буквенную часть оставить без изменений.
Пример: 3x + 5x – 2 = 14
Приводим подобные: 8x – 2 = 14
Пример с двух сторон: 4x + 2x – 5 = 3x + 10
Слева: 6x – 5 = 3x + 10

5. Раскрытие скобок

Если в уравнении есть скобки, их нужно раскрыть перед переносом.

5.1. Если перед скобками стоит «+»

Правило: Если перед скобками стоит плюс, то скобки просто убираем, а знаки внутри оставляем без изменений.
Пример: 5 + (3x – 2) = 5 + 3x – 2

5.2. Если перед скобками стоит «–»

Правило: Если перед скобками стоит минус, то скобки убираем, а знаки внутри меняем на противоположные.
Пример: 5 – (3x – 2) = 5 – 3x + 2

5.3. Число умножается на скобку

Правило: Чтобы умножить число на скобку, нужно умножить это число на каждое слагаемое внутри скобок.
a(b + c) = ab + ac a(b – c) = ab – ac –a(b + c) = –ab – ac –a(b – c) = –ab + ac
Пример: 2(x + 3) = 2x + 6
Пример: –3(x – 4) = –3x + 12

5.4. Скобка на скобку (для сильных)

Правило: Чтобы умножить скобку на скобку, нужно каждое слагаемое из первой скобки умножить на каждое слагаемое из второй.
(a + b)(c + d) = ac + ad + bc + bd
Пример: (x + 2)(x + 3) = x·x + x·3 + 2·x + 2·3 = x² + 3x + 2x + 6 = x² + 5x + 6

6. Алгоритм решения

Порядок действий: 1. Раскрыть все скобки. 2. Привести подобные в каждой части. 3. Перенести все слагаемые с x влево, числа — вправо. 4. Привести подобные. 5. Найти x (разделить обе части на коэффициент при x). 6. Сделать проверку.
Главное правило: все действия выполняем с обеими частями уравнения одновременно!
