Умножение, деление, степень

Правила знаков · Свойства · Коэффициент · Подобные слагаемые

1. Умножение. Правило знаков

Знак произведения зависит от количества отрицательных множителей:

  • Чётное количество отрицательных чисел → «+»
  • Нечётное количество отрицательных чисел → «–»
Примеры: (–2) · (–3) = 6; (–2) · 3 = –6; (–2) · (–3) · (–1) = –6
a · b — модули перемножаются, знак по правилу.

2. Деление. Правило знаков

Правило знаков для деления такое же, как и для умножения:

Примеры: (–8) : (–2) = 4; 12 : (–3) = –4
Важно: делить на 0 нельзя!

3. Свойства умножения

  • Переместительное: a · b = b · a
  • Сочетательное: (a · b) · c = a · (b · c)
  • Распределительное: a · (b + c) = a · b + a · c
  • Умножение на 0: a · 0 = 0
  • Умножение на 1: a · 1 = a
  • Умножение на –1: a · (–1) = –a

4. Свойства деления

  • Деление на 1: a : 1 = a
  • Деление на –1: a : (–1) = –a
  • Деление числа на само себя: a : a = 1 (при a ≠ 0)
Примеры: 15 : (–1) = –15; –7 : (–7) = 1

5. Связь умножения и деления

Если a · b = c, то c : b = a и c : a = b (при b, a ≠ 0).
Пример: 6 · (–5) = –30, значит –30 : (–5) = 6 и –30 : 6 = –5
Эти правила помогают проверять вычисления.

6. Степень с отрицательным основанием

Степень — это произведение нескольких одинаковых множителей.

aⁿ = a · a · ... · a (n раз)

Важно! Знак результата зависит от чётности показателя:

  • Чётный показатель → результат положительный.
  • Нечётный показатель → результат отрицательный.
Запомните: отрицательное число в чётной степени даёт положительное число, а в нечётной — отрицательное.

Со скобками

(–3)² = (–3) · (–3) = 9
(–2)³ = (–2) · (–2) · (–2) = –8
(–5)⁴ = (–5) · (–5) · (–5) · (–5) = 625
Скобки означают, что в степень возводится всё число вместе со знаком «–».

Без скобок

–3² = –(3 · 3) = –9
–2³ = –(2 · 2 · 2) = –8
–5⁴ = –(5 · 5 · 5 · 5) = –625
Ключевое отличие: (–a)ⁿ ≠ –aⁿ (при чётном n).
Скобки меняют знак результата!

Сравнение:

Пример: (–3)² = 9, а –3² = –9 → 9 ≠ –9
Пример: (–2)³ = –8, а –2³ = –8 → –8 = –8 (при нечётном показателе совпадают)
Вывод: Всегда обращайте внимание на скобки!
(–a)ⁿ — знак зависит от чётности n.
–aⁿ — сначала возводим a в степень, затем ставим «–».

7. Коэффициент

Коэффициент — это числовой множитель в произведении, где есть буквы (переменные).

Примеры:
в выражении 5x коэффициент равен 5;
в выражении –3y коэффициент равен –3;
в выражении ab коэффициент равен 1 (так как 1 · a · b);
в выражении –xy коэффициент равен –1.

Правила нахождения коэффициента:

  • Если перед буквой нет числа, коэффициент = 1 (например, a = 1 · a).
  • Если перед буквой стоит знак «–», коэффициент = –1 (например, –a = –1 · a).
  • Если в выражении несколько чисел и букв, перемножаем все числа — это и есть коэффициент.
Примеры:
7ab → коэффициент 7
–2,5xy → коэффициент –2,5
1,5 · 2 · a · b = 3ab → коэффициент 3

8. Подобные слагаемые

Подобные слагаемые — это слагаемые, у которых одинаковая буквенная часть.

Примеры подобных:
5x и –3x (буквенная часть x)
2ab и –7ab (буквенная часть ab)
4 и –9 (числа без букв — тоже подобные)
Примеры НЕ подобных:
5x и 5y (разные буквы)
2ab и 2a (разная буквенная часть)
3x и 3x² (разные степени)
Важно: у подобных слагаемых буквенная часть должна быть точно одинаковой!

9. Приведение подобных слагаемых

Привести подобные слагаемые — значит сложить их коэффициенты, а буквенную часть оставить без изменений.

Алгоритм:
1. Найти подобные слагаемые.
2. Сложить их коэффициенты.
3. Буквенную часть переписать.
Пример 1:
5x + 3x = (5 + 3)x = 8x
Пример 2:
7y – 2y = (7 – 2)y = 5y
Пример 3 (сложный):
3a + 5b – 2a + b = (3a – 2a) + (5b + b) = 1a + 6b = a + 6b
Пример 4 (с отрицательными):
–4x + 2x – 3x = (–4 + 2 – 3)x = –5x
Пример 5 (с числами):
8 + 3x – 5 + 2x = (8 – 5) + (3x + 2x) = 3 + 5x
Запомните: при приведении подобных складываются только коэффициенты, буквенная часть не меняется!
Совет: удобно подчёркивать подобные слагаемые одинаковыми линиями, чтобы не ошибиться.
