§1 Что такое функция

В жизни мы часто встречаем зависимость одних величин от других. Площадь квадрата зависит от его стороны, путь зависит от времени, температура — от времени суток.

Определение. Функция — это правило, по которому каждому значению независимой переменной (аргумента) соответствует ровно одно значение зависимой переменной (функции).
Обозначения:
\(x\) — независимая переменная (аргумент).
\(y\) — зависимая переменная (функция).
Запись \(y = f(x)\) означает: «\(y\) есть функция от \(x\)».
Значение функции \(f\) в точке \(x\) обозначают \(f(x)\).
Пример 1. Площадь квадрата зависит от его стороны:
\(S = a^2\).
Здесь \(a\) — независимая переменная (можно взять любую сторону), \(S\) — зависимая.
Если \(a = 3\), то \(S(3) = 3^2 = 9\).
Если \(a = 10\), то \(S(10) = 10^2 = 100\).
Пример 2. Путь автомобиля при скорости \(50\) км/ч:
\(s = 50t\).
Здесь \(t\) — время (аргумент), \(s\) — путь (функция).
Если \(t = 2\), то \(s(2) = 50 \cdot 2 = 100\) км.

§2 Область определения и область значений

Определение. Область определения — это множество всех чисел, которые могут являться аргументами данной функции (то есть все допустимые \(x\)).
Определение. Область значений — это множество всех чисел, которые могут являться значениями функции (то есть все возможные \(y\)).
Пример (периметр квадрата). \(P = 4a\).
Сторона квадрата \(a\) — это длина. Длина не может быть отрицательной и не может быть равна нулю (иначе квадрата не получится). Значит, \(a > 0\).
При умножении положительного числа \(a\) на \(4\) получается тоже только положительное число. Значит, \(P > 0\).
Область определения: \(a \in (0; +\infty)\).
Область значений: \(P \in (0; +\infty)\).
Полезно запомнить:
  • Если в функции есть деление на \(x\), то \(x \neq 0\) (или знаменатель \(\neq 0\)).
  • Если в функции есть квадратный корень, то подкоренное выражение \(\ge 0\).
  • Если функция описывает реальную величину (длину, время, массу), то она положительна.

§3 Как задать функцию

Одну и ту же функцию можно задать по-разному. Рассмотрим три основных способа.

1. Словесный способ.
«У Даши есть яблоки. При этом у её старшего брата Вани всегда на два яблока больше.»
Здесь словами описана зависимость количества яблок у Вани от количества яблок у Даши.
2. Табличный способ.
Составим таблицу аргументов и зависимых от них величин:
x (яблоки Даши) 1 2 3 4
y (яблоки Вани) 3 4 5 6
Видно, что каждое \(y\) больше своего \(x\) на \(2\).
3. Формульный способ.
Это самый удобный способ. Зависимость записывается в виде формулы:
\(y = x + 2\)
По формуле сразу видно, что каждый \(y\) на \(2\) больше, чем соответствующий ему \(x\).

§4 Как найти значение функции

Пример №1. Найдите значение функции \(y = \dfrac{x - 2}{5}\) при \(x = 2\) и \(x = 27\).

1) Подставим \(x = 2\):
\(f(2) = \dfrac{2 - 2}{5} = \dfrac{0}{5} = 0\).
Значит, аргументу \(2\) соответствует значение функции \(0\).

2) Подставим \(x = 27\):
\(f(27) = \dfrac{27 - 2}{5} = \dfrac{25}{5} = 5\).
Значит, аргументу \(27\) соответствует значение функции \(5\).

Ответ: \(0\); \(5\).

§5 График функции

Определение. Графиком функции называется множество всех точек координатной плоскости, абсциссы которых равны значениям аргумента, а ординаты — соответствующим значениям функции.

Любую функцию можно изобразить на координатной плоскости. Если точка принадлежит графику функции, её координаты — это (аргумент; значение функции).

Пример №2 (построение). Построим график функции \(y = x + 2\).

Шаг 1. Составим таблицу значений:
x -2 0 3 6
y 0 2 5 8
Шаг 2. У нас есть точки: \(A(-2; 0)\), \(B(0; 2)\), \(C(3; 5)\), \(D(6; 8)\).
Шаг 3. Отметим их на координатной плоскости и соединим. Получится прямая.
График функции \(y = x + 2\) — прямая линия
Важно: график функции не обязательно должен быть прямой линией. Он может быть параболой (как \(y = x^2\)), гиперболой, волной и т.д. Форма зависит от формулы.

§6 Равные треугольники

Определение. Два треугольника называются равными, если их можно совместить наложением. При этом все соответствующие стороны и углы равны.

Если \(\triangle ABC = \triangle A_1B_1C_1\), то порядок букв в записи равенства задаёт соответствие вершин:

\(A \leftrightarrow A_1, \quad B \leftrightarrow B_1, \quad C \leftrightarrow C_1\)

Из этого соответствия автоматически следуют равенства сторон и углов:

\(AB = A_1B_1, \quad BC = B_1C_1, \quad CA = C_1A_1\)
\(\angle A = \angle A_1, \quad \angle B = \angle B_1, \quad \angle C = \angle C_1\)
\(\triangle ABC = \triangle A_1B_1C_1\)

§7 Первый признак равенства треугольников

Теорема (первый признак). Если две стороны и угол между ними одного треугольника соответственно равны двум сторонам и углу между ними другого треугольника, то такие треугольники равны.
\(AB = A_1B_1, \quad AC = A_1C_1, \quad \angle A = \angle A_1\)
\(\Downarrow\)
\(\triangle ABC = \triangle A_1B_1C_1\)
Равные треугольники по двум сторонам и углу между ними
Важно! Угол обязательно должен лежать между этими сторонами. Если угол не между сторонами, первый признак не работает.

§8 Как применять первый признак

Чтобы доказать равенство треугольников по первому признаку, действуй по шагам:

  1. Найди две пары равных сторон в треугольниках. Обычно они даны в условии или видны на рисунке.
  2. Найди угол между этими сторонами в каждом треугольнике и докажи, что они равны.
  3. Сделай вывод: треугольники равны по первому признаку (по двум сторонам и углу между ними).
Пример. Дано: \(AB = A_1B_1\), \(AC = A_1C_1\), \(\angle A = \angle A_1\). Доказать: \(\triangle ABC = \triangle A_1B_1C_1\).
Рассмотрим \(\triangle ABC\) и \(\triangle A_1B_1C_1\):
\(AB = A_1B_1\) (по условию),
\(AC = A_1C_1\) (по условию),
\(\angle A = \angle A_1\) (по условию) — угол между сторонами \(AB\) и \(AC\).
Значит, \(\triangle ABC = \triangle A_1B_1C_1\) по первому признаку.
Схема оформления доказательства:
1) Рассмотрим \(\triangle \ldots\) и \(\triangle \ldots\)
2) \(\ldots = \ldots\) (по условию)
3) \(\ldots = \ldots\) (по условию)
4) \(\angle \ldots = \angle \ldots\) (по условию)
5) Значит, \(\triangle \ldots = \triangle \ldots\) по первому признаку.
