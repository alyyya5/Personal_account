§1 Что такое треугольник

Определение. Треугольником называется многоугольник с тремя вершинами. Он имеет три стороны и три угла.

На рисунке ниже изображён треугольник с вершинами \(A\), \(B\), \(C\) и сторонами \(AB\), \(BC\), \(CA\).

Треугольник \(ABC\)

Обозначение: \(\triangle ABC\). Буквы можно перечислять по обходу в любом порядке, но подряд: \(\triangle BCA\), \(\triangle CAB\) и т. д.

Углы треугольника — это \(\angle A\), \(\angle B\), \(\angle C\) (или \(\angle BAC\), \(\angle CBA\), \(\angle ACB\)).
Периметр треугольника равен сумме длин трёх его сторон:
\(P_{ABC} = AB + BC + CA\)

§2 Равные треугольники

Определение. Две фигуры, в частности два треугольника, называются равными, если их можно совместить наложением.

Если \(\triangle ABC\) и \(\triangle A_1B_1C_1\) равны, то при наложении полностью совместятся их вершины, стороны и углы.

\(\triangle ABC = \triangle A_1B_1C_1\)
Важно! В равных треугольниках против соответственно равных сторон лежат равные углы, и наоборот: против соответственно равных углов лежат равные стороны.

Например, если \(AB = A_1B_1\), то и угол \(C\) равен углу \(C_1\).

§3 Что такое линейное уравнение

Определение. Линейным уравнением с одной переменной называется уравнение вида \(ax = b\), где \(a\) и \(b\) — числа, \(x\) — переменная.

Примеры линейных уравнений:

\(3x = 12\)     \(5x - 8 = 2x + 4\)     \(0{,}5x = 7\)
Важно помнить:
  • Если \(a \neq 0\) — уравнение имеет один корень.
  • Если \(a = 0\), \(b = 0\) — бесконечно много корней (любое \(x\)).
  • Если \(a = 0\), \(b \neq 0\) — корней нет.

§4 Как решать линейное уравнение

План решения:
  1. Раскрыть скобки (если есть).
  2. Перенести слагаемые с переменной в одну часть, а числа — в другую. Знак меняется на противоположный.
  3. Привести подобные слагаемые в каждой части.
  4. Разделить обе части на коэффициент при переменной.
  5. Записать ответ.
Пример 1. \(4x - 7 = x + 8\)
\(4x - x = 8 + 7\)
\(3x = 15\)
\(x = 5\)
Ответ: \(5\).
Пример 2. \(6a - 12 = 3 - 3a\)
\(6a + 3a = 3 + 12\)
\(9a = 15\)
\(a = \dfrac{15}{9} = \dfrac{5}{3}\)
Ответ: \(\dfrac{5}{3}\).
Пример 3 (с дробями в коэффициентах). \(\dfrac{2}{5}x = \dfrac{1}{3}\)
\(x = \dfrac{1}{3} : \dfrac{2}{5} = \dfrac{1}{3} \cdot \dfrac{5}{2}\)
\(x = \dfrac{5}{6}\)
Ответ: \(\dfrac{5}{6}\).
Пример 4. \(1{,}2x + 3 = 0{,}4x - 5\)
\(1{,}2x - 0{,}4x = -5 - 3\)
\(0{,}8x = -8\)
\(x = -10\)
Ответ: \(-10\).

§5 Уравнения со скобками

Если в уравнении есть скобки, сначала их раскрывают, а потом решают как обычное линейное уравнение.

Правила раскрытия скобок:
  • Перед скобкой «+» — знаки не меняются.
  • Перед скобкой «−» — знаки всех слагаемых меняются на противоположные.
  • Число перед скобкой — умножаем на каждое слагаемое.
Пример 1. \((y + 5) - (y - 2) = 7y\)
\(y + 5 - y + 2 = 7y\)
\(7 = 7y\)
\(y = 1\)
Ответ: \(1\).
Пример 2. \(4p - 2 - (p + 4) = 2\)
\(4p - 2 - p - 4 = 2\)
\(3p - 6 = 2\)
\(3p = 8\)
\(p = \dfrac{8}{3}\)
Ответ: \(\dfrac{8}{3}\).
Пример 3. \(7x - (8x - 15) = 100\)
\(7x - 8x + 15 = 100\)
\(-x + 15 = 100\)
\(-x = 85\)
\(x = -85\)
Ответ: \(-85\).

§6 Двойные скобки

Если скобок несколько, раскрываем их по очереди: сначала одни, потом другие. Потом приводим подобные.

Пример 1. \((15x - 20) - (10 + 7x) = -4x\)
\(15x - 20 - 10 - 7x = -4x\)
\(8x - 30 = -4x\)
\(8x + 4x = 30\)
\(12x = 30\)
\(x = 2{,}5\)
Ответ: \(2{,}5\).
Пример 2. \(14 - (5x - 20) = (40 + 5x) + (20 - 7x)\)
\(14 - 5x + 20 = 40 + 5x + 20 - 7x\)
\(34 - 5x = 60 - 2x\)
\(-5x + 2x = 60 - 34\)
\(-3x = 26\)
\(x = -\dfrac{26}{3}\)
Ответ: \(-\dfrac{26}{3}\).
Совет: раскрывай скобки слева и справа по отдельности, потом приравнивай. Так меньше шансов ошибиться.
