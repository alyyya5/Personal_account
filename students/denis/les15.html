§1 Задачи на движение

В основе всех задач на движение лежит формула:

\(S = v \cdot t\)
Расстояние = Скорость \(\times\) Время
Как оформлять таблицу:
  • Столбцы: Скорость (\(v\)), Время (\(t\)), Расстояние (\(S\)).
  • За \(x\) обычно обозначают скорость.
  • Время выражают как \(t = \frac{S}{v}\).
  • Если в условии есть «на \(k\) часов быстрее/медленнее», составляют уравнение с разностью времен.
Особые случаи:
  • Движение навстречу: скорости складываются. Время до встречи: \(t = \frac{S}{v_1 + v_2}\).
  • Движение вдогонку: разность скоростей. Если один выехал позже, его время меньше на время задержки.
  • Поезда: чтобы найти время прохождения мимо друг друга, нужно сложить длины поездов и разделить на сумму (или разность) скоростей. Переведите км/ч в м/с, умножив на \(\frac{1000}{3600} = \frac{5}{18}\).

§2 Задачи на работу

Логика задач на работу полностью повторяет задачи на движение:

\(A = p \cdot t\)
Работа = Производительность \(\times\) Время
Схема: Если первый делает работу быстрее, он тратит меньше времени.
\(t_1 = \frac{A}{x}\), \(t_2 = \frac{A}{x - k}\) (где \(k\) — разница в производительности).
Уравнение: \(t_2 - t_1 = \text{разница во времени}\).

§3 Как решать показательные уравнения

Главный метод: привести обе части уравнения к одинаковому основанию.

Если \(a^{f(x)} = a^{g(x)}\), то \(f(x) = g(x)\)
Самые важные преобразования:
  • Десятичные дроби в обыкновенные: \(0{,}2 = \frac{1}{5}\), \(0{,}25 = \frac{1}{4}\).
  • Дробь — это отрицательная степень: \(\left(\frac{1}{5}\right)^x = 5^{-x}\).
  • Числа как степени: \(25 = 5^2\), \(125 = 5^3\), \(8 = 2^3\), \(4 = 2^2\).
  • Дробь как степень: \(\frac{1}{25} = 5^{-2}\), \(\frac{1}{64} = 4^{-3}\).
Пример-схема. Уравнение \(5^{2x-6} = \frac{1}{25}\).
Представляем: \(\frac{1}{25} = 5^{-2}\).
Получаем: \(5^{2x-6} = 5^{-2}\).
Приравниваем степени: \(2x - 6 = -2 \Rightarrow 2x = 4 \Rightarrow x = 2\).

§4 Логарифм в показателе степени

В некоторых задачах (№9, №14, №17) в степени стоит логарифм. Здесь работает основное логарифмическое тождество и его следствия.

\(a^{\log_a b} = b\)

Пример: \(3^{\log_3 7} = 7\).
Если основания разные:
Например, \(3^{\log_9(4x+1)} = 9\).
Нужно сделать основания одинаковыми. \(9 = 3^2\), значит \(3^{\log_{3^2}(4x+1)} = 3^2\).
По свойству \(\log_{a^n} b = \frac{1}{n}\log_a b\) получаем в показателе \(\frac{1}{2}\log_3(4x+1)\).
Приравниваем степени: \(\frac{1}{2}\log_3(4x+1) = 2\).

§5 Определение логарифма

Определение. Логарифм числа \(b\) по основанию \(a\) — это показатель степени, в которую нужно возвести \(a\), чтобы получить \(b\).
\(\log_a b = c \quad \Leftrightarrow \quad a^c = b\)
ОДЗ (обязательно проверяем!):
Основание \(a > 0\), \(a \neq 1\).
Аргумент \(b > 0\).

§6 Свойства логарифмов для решения

1. Равенство логарифмов:
\(\log_a f(x) = \log_a g(x) \implies f(x) = g(x)\)

2. Вынесение степени из аргумента:
\(\log_a (b^n) = n \cdot \log_a b\)

3. Вынесение степени из основания:
\(\log_{a^n} b = \frac{1}{n} \log_a b\)

4. Представление числа в виде логарифма:
\(c = \log_a (a^c)\)
Пример: \(1 = \log_5 5\), \(2 = \log_3 9\).
Пример-схема (степень в аргументе).
Уравнение \(\log_8 2^{8x-4} = 4\).
Выносим степень из аргумента: \((8x-4) \cdot \log_8 2 = 4\).
Так как \(8 = 2^3\), то \(\log_8 2 = \log_{2^3} 2 = \frac{1}{3}\).
Уравнение: \((8x-4) \cdot \frac{1}{3} = 4\).
Пример-схема (сложение логарифмов).
Уравнение \(\log_3(x+6) = \log_3(10-x) - 1\).
Единицу представляем как \(\log_3 3\).
Переносим: \(\log_3(x+6) + \log_3 3 = \log_3(10-x)\).
Слева сумма логарифмов: \(\log_3((x+6) \cdot 3) = \log_3(10-x)\).
Приравниваем аргументы: \(3(x+6) = 10-x\).
