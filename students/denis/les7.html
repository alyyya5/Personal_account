✦ ЛОГАРИФМЫ · ТЕОРИЯ ✦

§1 Что такое логарифм

Логарифм числа \(b\) по основанию \(a\) — это показатель степени, в которую нужно возвести \(a\), чтобы получить \(b\).

\(\log_a b = c \;\Longleftrightarrow\; a^c = b\)
⚠️ ОДЗ: аргумент \(b > 0\), основание \(a > 0\), \(a \neq 1\).
Обозначения: \(\lg b = \log_{10} b\) — десятичный, \(\ln b = \log_e b\) — натуральный.
◆ СВОЙСТВА ЛОГАРИФМОВ ◆

§2 Все свойства

Пусть \(a > 0\), \(a \neq 1\), \(b > 0\), \(c > 0\).

1. \(\log_a a = 1\)
2. \(\log_a 1 = 0\)
3. \(a^{\log_a b} = b\)
4. \(\log_a (bc) = \log_a b + \log_a c\)
5. \(\log_a \dfrac{b}{c} = \log_a b - \log_a c\)
6. \(\log_a b^n = n \cdot \log_a b\)
7. \(\log_{a^n} b = \dfrac{1}{n} \cdot \log_a b\)
8. \(\log_a b = \dfrac{\log_k b}{\log_k a}\)
◆ ПРОСТЕЙШИЕ УРАВНЕНИЯ ◆

§3 Уравнения вида \(\log_a x = c\)

\(\log_a x = c \;\Longleftrightarrow\; x = a^c\),   при \(x > 0\)
План решения:
  1. Найти ОДЗ: аргумент \(> 0\).
  2. Использовать определение: \(x = a^c\).
  3. Проверить корень по ОДЗ.
Пример. \(\log_2 x = 5\)
ОДЗ: \(x > 0\) \(x = 2^5 = 32\) Проверка: \(32 > 0\) ✔
Ответ: \(32\).
◆ ЛОГАРИФМЫ С ОБЕИХ СТОРОН ◆

§4 Уравнения \(\log_a f(x) = \log_a g(x)\)

\(\log_a f(x) = \log_a g(x) \;\Longrightarrow\; f(x) = g(x)\)
при условии \(f(x) > 0\) и \(g(x) > 0\)
План решения:
  1. Найти ОДЗ: \(f(x) > 0\) и \(g(x) > 0\).
  2. Приравнять аргументы: \(f(x) = g(x)\).
  3. Решить уравнение.
  4. Проверить корни по ОДЗ.
Пример. \(\log_3 (x + 2) = \log_3 (2x - 1)\)
ОДЗ: \(x + 2 > 0\) и \(2x - 1 > 0 \Rightarrow x > 0{,}5\) \(x + 2 = 2x - 1\) \(x = 3\) Проверка: \(3 > 0{,}5\) ✔
Ответ: \(3\).
⚠️ Внимание! Даже если уравнение решается легко, обязательно проверяй корни по ОДЗ. Посторонние корни отбрасываются.
◆ СУММА И РАЗНОСТЬ ЛОГАРИФМОВ ◆

§5 Уравнения с несколькими логарифмами

\(\log_a f(x) + \log_a g(x) = \log_a [f(x) \cdot g(x)]\)
\(\log_a f(x) - \log_a g(x) = \log_a \dfrac{f(x)}{g(x)}\)
План решения:
  1. Найти ОДЗ: все аргументы \(> 0\).
  2. Свернуть сумму (или разность) в один логарифм.
  3. Приравнять аргументы (или использовать определение).
  4. Решить уравнение и проверить корни по ОДЗ.
Пример. \(\log_2 x + \log_2 (x - 2) = 3\)
ОДЗ: \(x > 0\) и \(x - 2 > 0 \Rightarrow x > 2\) \(\log_2 [x(x - 2)] = 3\) \(x(x - 2) = 8\) \(x^2 - 2x - 8 = 0\) \(x_1 = 4\), \(x_2 = -2\) ОДЗ: \(x > 2 \Rightarrow\) подходит только \(x = 4\)
Ответ: \(4\).

Итог Порядок решения

  1. Найти ОДЗ — все аргументы логарифмов \(> 0\).
  2. Свернуть логарифмы слева и справа (если их несколько).
  3. Если основания одинаковые — приравнять аргументы.
  4. Если один логарифм — использовать определение.
  5. Решить получившееся уравнение.
  6. Проверить корни по ОДЗ.
⚠️ Запомни: под знаком логарифма всегда положительное число. Проверка корней — обязательна!
