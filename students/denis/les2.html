§1 Что такое модуль?

Модуль числа — это расстояние от этого числа до нуля на числовой прямой. Модуль всегда неотрицателен!

\(|x| = \begin{cases} x, & \text{если } x \ge 0 \\ -x, & \text{если } x < 0 \end{cases}\)
Примеры:
\(|5| = 5\) (так как 5 ≥ 0)
\(|-3| = -(-3) = 3\) (так как -3 < 0)
\(|0| = 0\)
Важно помнить:
  • \(|x| \ge 0\) для любого x (модуль не может быть отрицательным!)
  • \(|x| = |-x|\) (модули противоположных чисел равны)

§2 Простейшие уравнения |f(x)| = a

Рассмотрим уравнение \(|f(x)| = a\), где a — некоторое число.

⚠️ Важно: Так как модуль всегда ≥ 0, то:
  • Если a < 0, уравнение не имеет решений
  • Если a = 0, то f(x) = 0
  • Если a > 0, получаем два уравнения: f(x) = a или f(x) = -a
Пример 1. Решите уравнение \(|2x + 1| = -3\)
Решение:
Так как -3 < 0, а модуль не может быть отрицательным, уравнение не имеет решений.
Пример 2. Решите уравнение \(|x - 2| + 3 = 7\)
Решение:
Шаг 1: Перенесём 3 вправо: \(|x - 2| = 7 - 3\)
\(|x - 2| = 4\)

Шаг 2: Так как 4 > 0, получаем два уравнения:
\(\begin{cases} x - 2 = 4 \\ x - 2 = -4 \end{cases}\)

Шаг 3: Решаем каждое:
x - 2 = 4 ⟹ x = 6
x - 2 = -4 ⟹ x = -2

Ответ: x = 6; x = -2
Пример 3. Решите уравнение \(|3x - 7| = 5\)
Решение:
Так как 5 > 0, получаем:
\(\begin{cases} 3x - 7 = 5 \\ 3x - 7 = -5 \end{cases}\)

3x - 7 = 5 ⟹ 3x = 12 ⟹ x = 4
3x - 7 = -5 3x = 2 ⟹ x = \(\frac{2}{3}\)

Ответ: x = 4; x = \(\frac{2}{3}\)

§3 Уравнения |f(x)| = |g(x)|

Когда модули стоят с обеих сторон, используем простое правило:

\(|f(x)| = |g(x)|\) ⟹ \(\begin{cases} f(x) = g(x) \\ f(x) = -g(x) \end{cases}\)
Пример 1. Решите уравнение \(|2x - 3| = |x + 1|\)
Решение:
Получаем два уравнения:

1) 2x - 3 = x + 1
2x - x = 1 + 3
x = 4

2) 2x - 3 = -(x + 1)
2x - 3 = -x - 1
2x + x = -1 + 3
3x = 2
x = \(\frac{2}{3}\)

Ответ: x = 4; x = \(\frac{2}{3}\)
Пример 2. Решите уравнение \(|x - 5| = |3 - x|\)
Решение:
1) x - 5 = 3 - x
x + x = 3 + 5
2x = 8
x = 4

2) x - 5 = -(3 - x)
x - 5 = -3 + x
x - x = -3 + 5
0 = 2 — неверно!

Ответ: x = 4

§4 Уравнения |f(x)| = g(x)

Когда справа стоит выражение с переменной, обязательно нужно ограничение!

⚠️ Алгоритм решения:
Шаг 1: Записать ограничение: g(x) ≥ 0
(потому что слева модуль, а он ≥ 0)
Шаг 2: Решить совокупность:
\(\begin{cases} f(x) = g(x) \\ f(x) = -g(x) \end{cases}\)
Шаг 3: Проверить найденные корни на соответствие ограничению
Пример 1. Решите уравнение \(|x^2 - 4| = x - 2\)
Решение:

Шаг 1: Ограничение: x - 2 ≥ 0 x ≥ 2

Шаг 2: Решаем два уравнения:

1) x² - 4 = x - 2
x² - x - 2 = 0
D = 1 + 8 = 9
x₁ = \(\frac{1+3}{2}\) = 2; x₂ = \(\frac{1-3}{2}\) = -1

2) x² - 4 = -(x - 2)
x² - 4 = -x + 2
x² + x - 6 = 0
D = 1 + 24 = 25
x₁ = \(\frac{-1+5}{2}\) = 2; x₂ = \(\frac{-1-5}{2}\) = -3

Шаг 3: Проверка ограничения x ≥ 2:
x = 2 ✓ (подходит)
x = -1 ✗ (не подходит)
x = -3 ✗ (не подходит)

Ответ: x = 2
Пример 2. Решите уравнение \(|2x + 1| = x + 4\)
Решение:

Шаг 1: Ограничение: x + 4 ≥ 0 x ≥ -4

Шаг 2: Решаем:

1) 2x + 1 = x + 4
2x - x = 4 - 1
x = 3

2) 2x + 1 = -(x + 4)
2x + 1 = -x - 4
2x + x = -4 - 1
3x = -5
x = \(-\frac{5}{3}\) ≈ -1,67

Шаг 3: Проверка x ≥ -4:
x = 3 ≥ -4 ✓
x = -5/3 ≥ -4 ✓

Ответ: x = 3; x = \(-\frac{5}{3}\)

§5 Квадратный трёхчлен под модулем

Когда под модулем стоит квадратный трёхчлен, используем метод интервалов.

📋 Алгоритм:
Шаг 1: Найти корни квадратного трёхчлена ax² + bx + c = 0
Шаг 2: Отметить их на числовой прямой и определить знаки
Шаг 3: Раскрыть модуль на каждом интервале:
  • Если трёхчлен ≥ 0, то |ax² + bx + c| = ax² + bx + c
  • Если трёхчлен < 0, то |ax² + bx + c| = -(ax² + bx + c)
Шаг 4: Решить уравнение на каждом интервале и проверить принадлежность
Пример. Решите уравнение \(|x^2 - 5x + 6| = 2\)
Решение:

Шаг 1: Находим корни x² - 5x + 6 = 0
D = 25 - 24 = 1
x₁ = \(\frac{5+1}{2}\) = 3; x₂ = \(\frac{5-1}{2}\) = 2

Шаг 2: Определяем знаки:
• При x < 2: трёхчлен > 0 (плюс)
• При 2 < x < 3: трёхчлен < 0 (минус)
• При x > 3: трёхчлен > 0 (плюс)

Шаг 3: Решаем на каждом промежутке:

1) x ≤ 2 или x ≥ 3 (где трёхчлен ≥ 0):
x² - 5x + 6 = 2
x² - 5x + 4 = 0
D = 25 - 16 = 9
x₁ = \(\frac{5+3}{2}\) = 4; x₂ = \(\frac{5-3}{2}\) = 1
Проверка: 1 ≤ 2 ✓; 4 ≥ 3 ✓

2) 2 < x < 3 (где трёхчлен < 0):
-(x² - 5x + 6) = 2
-x² + 5x - 6 = 2
x² - 5x + 8 = 0
D = 25 - 32 = -7 < 0
Корней нет

Ответ: x = 1; x = 4
Пример 2. Решите уравнение \(|x^2 - 4x + 3| = 0\)
Решение:

Модуль равен 0 только когда выражение под модулем равно 0:

x² - 4x + 3 = 0
D = 16 - 12 = 4
x₁ = \(\frac{4+2}{2}\) = 3; x₂ = \(\frac{4-2}{2}\) = 1

Ответ: x = 1; x = 3

§6 Особые случаи

Случай 1: Сумма модулей равна нулю
Если \(|f(x)| + |g(x)| = 0\), то оба модуля должны быть равны нулю:
\(\begin{cases} f(x) = 0 \\ g(x) = 0 \end{cases}\)

Пример: \(|x - 2| + |x + 3| = 0\)
\(\begin{cases} x - 2 = 0 \\ x + 3 = 0 \end{cases}\) ⟹ \(\begin{cases} x = 2 \\ x = -3 \end{cases}\)
Эти значения не совпадают, значит решений нет.
Случай 2: Модуль в модуле
\(||f(x)|| = |f(x)|\) — внешний модуль можно убрать!

Пример: \(||x - 3|| = 5\)
|x - 3| = 5
\(\begin{cases} x - 3 = 5 \\ x - 3 = -5 \end{cases}\)
x = 8; x = -2

Ответ: x = 8; x = -2
⚠️ Частые ошибки:
  • Забыли проверить ограничение в уравнениях вида |f(x)| = g(x)
  • Потеряли корни — не рассмотрели оба случая
  • Неверно раскрыли модуль: |-x| = x (неверно!), правильно: |-x| = |x|

§7 Сводка алгоритмов

1. |f(x)| = a:
Если a < 0 — нет решений
Если a = 0 — f(x) = 0
Если a > 0 — \(\begin{cases} f(x) = a \\ f(x) = -a \end{cases}\)
2. |f(x)| = |g(x)|:
\(\begin{cases} f(x) = g(x) \\ f(x) = -g(x) \end{cases}\)
3. |f(x)| = g(x):
\(\begin{cases} g(x) \ge 0 \\ \begin{cases} f(x) = g(x) \\ f(x) = -g(x) \end{cases} \end{cases}\)
Совет: Всегда проверяйте свои ответы подстановкой в исходное уравнение!
