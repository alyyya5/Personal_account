Квадратные уравнения, степени и корни

Теория для подготовки · Задания 1, 5, 6 ЕГЭ Профиль

1. Формулы сокращённого умножения

📖 Три кита алгебры

Без этих формул невозможно решить ни одно сложное уравнение.

\[ (a \pm b)^2 = a^2 \pm 2ab + b^2 \] \[ a^2 - b^2 = (a-b)(a+b) \] \[ (a \pm b)^3 = a^3 \pm 3a^2b + 3ab^2 \pm b^3 \]
⚠️ Частая ошибка: \((a+b)^2 \neq a^2 + b^2\). Не забывай удвоенное произведение \(2ab\)!

2. Квадратные уравнения

📖 Определение

Квадратное уравнение — уравнение вида \(ax^2 + bx + c = 0\), где \(a \neq 0\).

Способы решения

1. Дискриминант

\[ D = b^2 - 4ac \] \[ x_{1,2} = \frac{-b \pm \sqrt{D}}{2a} \]
  • Если \(D > 0\) — два корня.
  • Если \(D = 0\) — один корень (два совпадающих).
  • Если \(D < 0\) — корней нет.

2. Теорема Виета (для приведённого \(x^2 + px + q = 0\))

\[ x_1 + x_2 = -p \] \[ x_1 \cdot x_2 = q \]

3. Неполные квадратные

  • \(ax^2 + bx = 0\) → \(x(ax + b) = 0\)
  • \(ax^2 + c = 0\) → \(x^2 = -c/a\)

4. Особый случай

Если \(a + b + c = 0\), то корни: \(x_1 = 1\), \(x_2 = c/a\).
Если \(a - b + c = 0\), то корни: \(x_1 = -1\), \(x_2 = -c/a\).

Биквадратные уравнения

Уравнение вида \(ax^4 + bx^2 + c = 0\).
Замена: \(t = x^2\), тогда \(at^2 + bt + c = 0\).
Найти \(t\), затем \(x = \pm \sqrt{t}\) (при \(t \geq 0\)).
⚠️ Важно: при замене \(t = x^2\) должно выполняться \(t \geq 0\)!

3. Свойства степеней

📖 Золотые правила

Цель показательного уравнения — привести обе части к одному основанию.

\[ a^n \cdot a^m = a^{n+m} \] \[ \frac{a^n}{a^m} = a^{n-m} \] \[ (a^n)^m = a^{n \cdot m} \] \[ a^{-n} = \frac{1}{a^n} \] \[ a^{\frac{1}{n}} = \sqrt[n]{a} \] \[ a^0 = 1 \quad (a \neq 0) \] \[ a^1 = a \]
Пример: \(2^x \cdot 4 = 32\)
Приводим к основанию 2: \(2^x \cdot 2^2 = 2^5\)
\(2^{x+2} = 2^5\) → \(x+2=5\) → \(x=3\)
💡 Для показательных уравнений: если основания равны, то равны показатели!

4. Иррациональные уравнения

📖 Определение

Иррациональное уравнение — уравнение, в котором переменная содержится под знаком корня.

Алгоритм решения

  1. Найти ОДЗ (подкоренное выражение \(\geq 0\)).
  2. Уединить корень (оставить его в одной части).
  3. Возвести обе части в квадрат (или в нужную степень).
  4. Решить полученное уравнение.
  5. Проверить корни по ОДЗ.
⚠️ Важно: при возведении в квадрат могут появиться посторонние корни!

Два главных типа

Тип 1: \(\sqrt{f(x)} = g(x)\)

\[ \begin{cases} f(x) = (g(x))^2 \\ g(x) \geq 0 \end{cases} \]

Тип 2: \(\sqrt{f(x)} = \sqrt{g(x)}\)

\[ \begin{cases} f(x) = g(x) \\ f(x) \geq 0 \end{cases} \]

Корни нечётной степени

\(\sqrt[3]{x} = a\) → \(x = a^3\)
ОДЗ не требуется (корень нечётной степени определён при любом \(x\)).
💡 Корень чётной степени — ОДЗ обязательна! Корень нечётной степени — ОДЗ не нужна.

5. Сводка правил

📌 Квадратные уравнения

  • \(ax^2 + bx + c = 0\)
  • Дискриминант: \(D = b^2 - 4ac\)
  • Виета: \(x_1+x_2 = -p\), \(x_1 \cdot x_2 = q\)
  • Неполные: вынести \(x\) или \(x^2 = -c/a\)
  • Биквадратные: замена \(t = x^2\)

📌 Свойства степеней

  • \(a^n \cdot a^m = a^{n+m}\)
  • \(\frac{a^n}{a^m} = a^{n-m}\)
  • \((a^n)^m = a^{n \cdot m}\)
  • \(a^{-n} = \frac{1}{a^n}\)
  • \(a^{\frac{1}{n}} = \sqrt[n]{a}\)
  • \(a^0 = 1\) (при \(a \neq 0\))

📌 Иррациональные уравнения

  • Найти ОДЗ (подкоренное \(\geq 0\)).
  • Уединить корень.
  • Возвести в квадрат.
  • Решить уравнение.
  • Проверить корни по ОДЗ.
  • Корень чётной степени → ОДЗ обязательна.
  • Корень нечётной степени → ОДЗ не нужна.

📌 ФСУ

  • \((a \pm b)^2 = a^2 \pm 2ab + b^2\)
  • \(a^2 - b^2 = (a-b)(a+b)\)
  • \((a \pm b)^3 = a^3 \pm 3a^2b + 3ab^2 \pm b^3\)
  • ⚠️ \((a+b)^2 \neq a^2 + b^2\)

📌 Главное правило: все действия выполняем с обеими частями уравнения одновременно!
