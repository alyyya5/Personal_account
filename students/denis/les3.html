Логарифмы и показательные уравнения

Теория для подготовки · Задание №6 ЕГЭ Профиль

1. Что такое логарифм

📖 Определение

Логарифм числа \(b\) по основанию \(a\) — это показатель степени, в которую нужно возвести \(a\), чтобы получить \(b\).

\[ \log_a b = c \iff a^c = b \quad (a > 0,\; a \neq 1,\; b > 0) \]
Примеры:
\(\log_2 8 = 3\), потому что \(2^3 = 8\)
\(\log_3 \frac{1}{9} = -2\), потому что \(3^{-2} = \frac{1}{9}\)
\(\log_5 1 = 0\), потому что \(5^0 = 1\)
⚠️ ОДЗ логарифма: выражение под знаком логарифма строго больше 0, основание \(a > 0\) и \(a \neq 1\).

📌 Десятичный и натуральный логарифмы

  • Десятичный: \(\lg b = \log_{10} b\)
  • Натуральный: \(\ln b = \log_e b\), где \(e \approx 2.718\)

2. Свойства логарифмов

📖 Базовые тождества

\[ \log_a a = 1 \qquad \log_a 1 = 0 \qquad a^{\log_a b} = b \quad \text{(основное тождество)} \]

✏️ Действия с логарифмами

\[ \log_a (xy) = \log_a x + \log_a y \] \[ \log_a \left(\frac{x}{y}\right) = \log_a x - \log_a y \] \[ \log_a (x^n) = n \cdot \log_a x \]

🔥 Степени в основании и переходе

\[ \log_{a^n} x = \frac{1}{n}\log_a x \qquad \log_{a^n} x^m = \frac{m}{n}\log_a x \] \[ \log_a b = \frac{\log_c b}{\log_c a} \quad \text{(переход к новому основанию)} \] \[ \log_a b = \frac{1}{\log_b a} \]
Пример перехода: \(\log_4 8 = \dfrac{\log_2 8}{\log_2 4} = \dfrac{3}{2}\)

3. Логарифмическая функция

📖 Функция \(y = \log_a x\)

Область определения: \(x > 0\)
Область значений: все действительные числа

📌 Свойства

  • График проходит через точку \((1; 0)\), так как \(\log_a 1 = 0\).
  • Вертикальная асимптота \(x = 0\) (ось \(y\)).
  • При \(a > 1\) функция возрастает.
  • При \(0 < a < 1\) функция убывает.
  • График логарифмической функции — зеркальное отражение показательной функции \(y = a^x\) относительно прямой \(y = x\).
💡 Логарифмическая и показательная функции — взаимно обратные.

4. Как решать логарифмические уравнения

📖 Метод 1: По определению

\(\log_3 (2x-1) = 2 \Rightarrow 2x - 1 = 3^2 = 9 \Rightarrow x = 5\)

📖 Метод 2: Потенцирование (одинаковые основания)

\(\log_5 f(x) = \log_5 g(x) \Rightarrow f(x) = g(x)\) + проверка ОДЗ!

📖 Метод 3: Замена переменной

\(\log_3^2 x - 2\log_3 x - 3 = 0\).
Замена \(t = \log_3 x\): \(t^2 - 2t - 3 = 0 \Rightarrow t = 3\) или \(t = -1\).
Тогда \(x = 27\) или \(x = \frac{1}{3}\).

📖 Метод 4: Свернуть сумму в один логарифм

\(\log_2 x + \log_2 (x-3) = 2 \Rightarrow \log_2 (x(x-3)) = \log_2 4 \Rightarrow x(x-3) = 4\)
⚠️ После решения всегда проверяй корни по ОДЗ!

5. Показательные уравнения

📖 Стратегия

Привести обе части к одному основанию, затем приравнять показатели.

\[ a^{f(x)} = a^{g(x)} \iff f(x) = g(x) \quad (a > 0,\; a \neq 1) \]

✏️ Методы решения

1. Приведение к одному основанию

\(4^x = 8^{x-1} \Rightarrow (2^2)^x = (2^3)^{x-1} \Rightarrow 2^{2x} = 2^{3x-3} \Rightarrow 2x = 3x - 3 \Rightarrow x = 3\)

2. Вынесение общего множителя

\(5^{x+2} - 5^x = 600 \Rightarrow 5^x(25 - 1) = 600 \Rightarrow 5^x \cdot 24 = 600 \Rightarrow 5^x = 25 \Rightarrow x = 2\)

3. Замена переменной

\(4^x - 5 \cdot 2^x + 4 = 0 \Rightarrow (2^x)^2 - 5 \cdot 2^x + 4 = 0\)
Замена \(t = 2^x > 0\): \(t^2 - 5t + 4 = 0 \Rightarrow t = 1\) или \(t = 4\)
Тогда \(x = 0\) или \(x = 2\).
💡 При замене \(t = a^x\) всегда \(t > 0\)!

6. Смешанные уравнения

📖 Главный инструмент

Основное логарифмическое тождество убирает логарифм из показателя:

\[ a^{\log_a b} = b \]
Пример: \(4^{\log_2 x} = (2^2)^{\log_2 x} = 2^{2\log_2 x} = 2^{\log_2 x^2} = x^2\)

✏️ Типы смешанных уравнений

Тип 1: \(a^{\log_a f(x)} = g(x)\)

\(5^{\log_5 (2x - 1)} = 7 \Rightarrow 2x - 1 = 7 \Rightarrow x = 4\)

Тип 2: \(\log_a (b^x + c) = d\)

\(\log_3 (2^x + 1) = 1 \Rightarrow 2^x + 1 = 3 \Rightarrow 2^x = 2 \Rightarrow x = 1\)

Тип 3: \(a^{\log_a f(x)} = g(x)\) с квадратом

\(4^{\log_2 x} = 9 \Rightarrow x^2 = 9 \Rightarrow x = 3\) (ОДЗ: \(x > 0\))

7. Сводка правил

📌 Логарифмы

  • \(\log_a b = c \iff a^c = b\)
  • \(\log_a a = 1,\; \log_a 1 = 0\)
  • \(\log_a (xy) = \log_a x + \log_a y\)
  • \(\log_a (x/y) = \log_a x - \log_a y\)
  • \(\log_a (x^n) = n \cdot \log_a x\)
  • \(\log_a b = \frac{\log_c b}{\log_c a}\)
  • \(a^{\log_a b} = b\)
  • ОДЗ: \(x > 0,\; a > 0,\; a \neq 1\)

📌 Показательные

  • \(a^{f(x)} = a^{g(x)} \iff f(x) = g(x)\)
  • Привести к одному основанию
  • Вынести общий множитель
  • Замена \(t = a^x > 0\)

📌 ОДЗ логарифма

  • Аргумент логарифма строго > 0
  • Основание \(a > 0,\; a \neq 1\)
  • После решения всегда проверять!

📌 Функция \(y = \log_a x\)

  • Область определения: \(x > 0\)
  • Проходит через \((1; 0)\)
  • Асимптота: \(x = 0\)
  • При \(a > 1\): возрастает
  • При \(0 < a < 1\): убывает

📌 Главное правило: в логарифмических уравнениях ОДЗ — первым делом!
