Формулы сокращённого умножения
Базовые тождества

Квадрат суммы и квадрат разности

\[(a \pm b)^2 = a^2 \pm 2ab + b^2\]
Пример 1: \((x + 5)^2 = x^2 + 2 \cdot x \cdot 5 + 5^2 = x^2 + 10x + 25\)
Пример 2: \((3a - 4)^2 = (3a)^2 - 2 \cdot 3a \cdot 4 + 4^2 = 9a^2 - 24a + 16\)

Разность квадратов

\[a^2 - b^2 = (a - b)(a + b)\]
Пример разложения: \(x^2 - 49 = x^2 - 7^2 = (x - 7)(x + 7)\)
Пример умножения: \((2x + 3y)(2x - 3y) = (2x)^2 - (3y)^2 = 4x^2 - 9y^2\)

Комбинированное упрощение

Алгоритм: Сначала раскройте каждую скобку по формуле, затем приведите подобные слагаемые.
Пример: \((a + 2)^2 - (a - 2)^2 = (a^2 + 4a + 4) - (a^2 - 4a + 4) = a^2 + 4a + 4 - a^2 + 4a - 4 = 8a\)

Квадратные уравнения
От Виета до дискриминанта

Приведённое квадратное уравнение (\(a = 1\)) и Теорема Виета

Для уравнения вида \(x^2 + px + q = 0\) корни \(x_1\) и \(x_2\) связаны соотношениями:

\[x_1 + x_2 = -p \quad \text{и} \quad x_1 \cdot x_2 = q\]
Пример: \(x^2 - 7x + 12 = 0\)
Ищем два числа, сумма которых равна \(7\), а произведение \(12\).
Это числа \(3\) и \(4\). Ответ: \(3; 4\)

Полное квадратное уравнение (\(a \neq 1\)) и Дискриминант

Для уравнения \(ax^2 + bx + c = 0\) основной алгоритм решения:

\[D = b^2 - 4ac\]
  • Если \(D > 0\), два корня: \(x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}\)
  • Если \(D = 0\), один корень: \(x = \frac{-b}{2a}\)
  • Если \(D < 0\), действительных корней нет.
Пример: \(2x^2 - 9x + 4 = 0\)
\(D = (-9)^2 - 4 \cdot 2 \cdot 4 = 81 - 32 = 49\)
\(x_1 = \frac{9 + 7}{4} = 4\); \(x_2 = \frac{9 - 7}{4} = 0.5\). Ответ: \(0.5; 4\)

Разложение квадратного трёхчлена на множители

\[ax^2 + bx + c = a(x - x_1)(x - x_2)\]
Важно: Если \(D < 0\), квадратный трёхчлен нельзя разложить на множители с действительными коэффициентами.

Свойства степеней
Правила действий

Основные свойства (для \(a \neq 0, b \neq 0\))

1. Умножение: \(a^m \cdot a^n = a^{m+n}\)
2. Деление: \(a^m : a^n = a^{m-n}\)
3. Возведение в степень: \((a^m)^n = a^{m \cdot n}\)
4. Степень произведения: \((ab)^n = a^n b^n\)
5. Отрицательная степень: \(a^{-n} = \frac{1}{a^n}\)
Примеры:
• \(a^3 \cdot a^5 = a^{3+5} = a^8\)
• \((a^2)^4 = a^{2 \cdot 4} = a^8\)
• \(a^7 : a^3 = a^{7-3} = a^4\)
• \((ab)^5 = a^5b^5\)
• \(a^{-3} = \frac{1}{a^3}\)

Показательные уравнения
Метод приведения к одному основанию

Основной принцип решения

Если обе части уравнения можно представить как степени с одинаковым основанием (\(a > 0, a \neq 1\)), то можно приравнять показатели:

\[a^{f(x)} = a^{g(x)} \quad \Longrightarrow \quad f(x) = g(x)\]
Полезные замены:
• \(81 = 3^4\), \(\frac{1}{16} = 2^{-4}\), \(343 = 7^3\)
• \(9^x = (3^2)^x = 3^{2x}\)
• \(27^{x-1} = (3^3)^{x-1} = 3^{3(x-1)}\)
Пример 1 (сложение степеней): \(3^{x+1} \cdot 3^{x-2} = 81\)
\(3^{(x+1) + (x-2)} = 3^4\)
\(3^{2x-1} = 3^4 \Rightarrow 2x - 1 = 4 \Rightarrow 2x = 5 \Rightarrow x = 2.5\)
Пример 2 (разные основания): \(9^x = 27^{x-1}\)
\((3^2)^x = (3^3)^{x-1}\)
\(3^{2x} = 3^{3x-3} \Rightarrow 2x = 3x - 3 \Rightarrow x = 3\)
Пример 3 (отрицательный показатель): \(2^{3x} = \frac{1}{16}\)
\(2^{3x} = 2^{-4} \Rightarrow 3x = -4 \Rightarrow x = -\frac{4}{3}\)
