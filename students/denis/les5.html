Логарифмы и показательные уравнения

Теория · Задание №7 ЕГЭ Профиль
1 Определение логарифма
№ Правило Формула / Смысл
1.1 Определение логарифма \(\log_a b = c \iff a^c = b\)
1.2 Десятичный логарифм \(\lg b = \log_{10} b\)
1.3 Натуральный логарифм \(\ln b = \log_e b,\; e \approx 2{,}718\)
⚠️ ОДЗ логарифма
  • Аргумент: \(b > 0\)
  • Основание: \(a > 0\), \(a \neq 1\)
2 Свойства логарифмов
№ Правило Формула
2.1 Логарифм основания \(\log_a a = 1\)
2.2 Логарифм единицы \(\log_a 1 = 0\)
2.3 Основное тождество \(a^{\log_a b} = b\)
2.4 Логарифм произведения \(\log_a (xy) = \log_a x + \log_a y\)
2.5 Логарифм частного \(\log_a \dfrac{x}{y} = \log_a x - \log_a y\)
2.6 Логарифм степени \(\log_a (x^n) = n \cdot \log_a x\)
2.7 Степень в основании \(\log_{a^n} x = \dfrac{1}{n}\log_a x\)
2.8 Степень в основании и аргументе \(\log_{a^n} x^m = \dfrac{m}{n}\log_a x\)
2.9 Переход к новому основанию \(\log_a b = \dfrac{\log_c b}{\log_c a}\)
2.10 Обратный логарифм \(\log_a b = \dfrac{1}{\log_b a}\)
3 Показательные выражения
№ Правило Формула
3.1 Равенство степеней \(a^{f(x)} = a^{g(x)} \iff f(x) = g(x)\)
3.2 Условие для замены \(t = a^x > 0\)
3.3 Свойство степеней \(a^{m+n} = a^m \cdot a^n\)
3.4 Свойство степеней \((a^m)^n = a^{mn}\)
4 Логарифмическая функция \(y = \log_a x\)
№ Свойство Значение
4.1 Область определения \(x > 0\)
4.2 Область значений \(y \in \mathbb{R}\)
4.3 Нулевая точка График проходит через \((1;\,0)\)
4.4 Асимптота Вертикальная: \(x = 0\)
4.5 Поведение при \(a > 1\) Возрастает
4.6 Поведение при \(0 < a < 1\) Убывает
4.7 Связь с показательной Взаимно обратные функции; график симметричен \(y = a^x\) относительно \(y = x\)
5 Смешанные выражения
№ Правило Формула
5.1 Основное тождество \(a^{\log_a b} = b\)
5.2 Степень с логарифмом \(a^{n \log_a b} = b^n\)
5.3 Логарифм от степени \(\log_a a^k = k\)
📌 Главное правило: в логарифмических выражениях ОДЗ — первым делом!
