§1 Задачи на совместную работу

В задачах на работу (кондитер печет конфеты, насос качает воду) действует та же логика, что и в задачах на движение.

Главная формула:
\(A = p \cdot t\)
Работа (A) = Производительность (p) \(\times\) Время (t)
Как оформлять задачу (метод таблицы):
  1. Обозначаем за \(x\) обычно производительность (сколько конфет в час, сколько литров в минуту).
  2. Заполняем столбцы: Работа (\(A\)), Производительность (\(p\)), Время (\(t\)).
  3. Время вычисляется как \(t = \frac{A}{p}\).
  4. Составляем уравнение, используя разницу во времени («на 4 часа быстрее/медленнее») или общее время.
Пример (схема для Задачи №1).
Работа = 285 конфет.
Пусть \(p\) первого = \(x\) конфет/час. Тогда \(p\) второго = \((x - 4)\) конфет/час.
Время первого: \(\frac{285}{x}\).
Время второго: \(\frac{285}{x-4}\).
Так как первый делает быстрее (тратит меньше времени), уравнение имеет вид:
\(\frac{285}{x-4} - \frac{285}{x} = 4\).

§2 Метод группировки (Задачи №3, 4, 7, 8)

Если в числителе или знаменателе стоит многочлен из 4 и более слагаемых, их нужно сгруппировать, чтобы вынести общий множитель.

Пример (из №3): \(bc + 3ac - 2ab - 6a^2\).
Группируем первое со вторым, а третье с четвертым:
\(c(b + 3a) - 2a(b + 3a)\).
Теперь выносим общую скобку \((b + 3a)\):
\((b + 3a)(c - 2a)\).
А в знаменателе \((c^2 - 4a^2)\) — это разность квадратов: \((c - 2a)(c + 2a)\).
Дробь отлично сокращается!

§3 Разность квадратов и корни (Задачи №4, 6, 7, 8)

Формула разности квадратов работает не только с обычными числами, но и с квадратными корнями.

\(a^2 - b^2 = (a - b)(a + b)\)

Для корней:
\(x^2 - (\sqrt{k})^2 = (x - \sqrt{k})(x + \sqrt{k})\)
Пример (из №6): Выражение \(\frac{4x - 25y}{2\sqrt{x} - 5\sqrt{y}}\).
Заметим, что \(4x = (2\sqrt{x})^2\), а \(25y = (5\sqrt{y})^2\).
Числитель раскладывается как разность квадратов: \((2\sqrt{x} - 5\sqrt{y})(2\sqrt{x} + 5\sqrt{y})\).
Знаменатель сокращается, остается просто \(2\sqrt{x} + 5\sqrt{y}\).

§4 Свойства степеней (Задачи №9, 10)

\(\dfrac{a^n}{a^m} = a^{n-m}\)

\(a^0 = 1\)
Пример (из №9): Выражение \(\frac{31 \cdot (x - 2017)^{2017}}{(x - 2017)^2}\) при \(x = 2018\).
Сначала подставим \(x = 2018\):
\(x - 2017 = 2018 - 2017 = 1\).
Получаем: \(\frac{31 \cdot 1^{2017}}{1^2} = 31 \cdot 1 = 31\).

§5 Как решать

Главный метод решения простейших показательных уравнений — приведение к одному основанию.

Если \(a^{f(x)} = a^{g(x)}\), то \(f(x) = g(x)\)
Полезные преобразования:
  • Десятичные дроби переводим в обыкновенные: \(0{,}2 = \frac{1}{5}\), \(0{,}04 = \frac{1}{25}\).
  • Отрицательная степень: \(\left(\frac{1}{5}\right)^{-n} = 5^n\).
  • Числа типа 125 представляем как степень: \(125 = 5^3\).
Пример (из №16): \(0{,}2^{5+4x} = 125\).
Переведем \(0{,}2\) в \(\frac{1}{5}\), а \(125\) в \(5^3\).
\(\left(\frac{1}{5}\right)^{5+4x} = 5^3\).
Перевернем левую дробь (поменяем знак степени):
\(5^{-(5+4x)} = 5^3\).
Основания равны, приравниваем степени:
\(-(5 + 4x) = 3 \implies -5 - 4x = 3 \implies -4x = 8 \implies x = -2\).

§6 Определение логарифма

Определение. Логарифм числа \(b\) по основанию \(a\) — это показатель степени, в которую нужно возвести \(a\), чтобы получить \(b\).
\(\log_a b = c \quad \Leftrightarrow \quad a^c = b\)
Ограничения (ОДЗ):
\(a > 0\), \(a \neq 1\) (основание), \(b > 0\) (аргумент).

§7 Свойства логарифмов

Для решения задач вам понадобятся следующие свойства:

1. Сложение логарифмов (с одинаковым основанием):
\(\log_a b + \log_a c = \log_a(b \cdot c)\)

2. Вынесение степени из аргумента:
\(n \log_a b = \log_a (b^n)\)

3. Логарифм основания:
\(\log_a a = 1\)

4. Равенство логарифмов:
\(\log_a f(x) = \log_a g(x) \implies f(x) = g(x)\) (при условии \(f(x)>0, g(x)>0\))
Пример (из №21): \(\log_5(5-x) = 2\log_5 3\).
Сначала внесем двойку внутрь логарифма как степень:
\(2\log_5 3 = \log_5(3^2) = \log_5 9\).
Уравнение принимает вид:
\(\log_5(5-x) = \log_5 9\).
Приравниваем аргументы:
\(5 - x = 9 \implies -x = 4 \implies x = -4\). (Не забываем проверить ОДЗ: \(5 - (-4) = 9 > 0\) — подходит).
Пример (из №23): \(\log_5(7-x) = \log_5(3-x) + 1\).
Единицу представляем как \(\log_5 5\).
\(\log_5(7-x) = \log_5(3-x) + \log_5 5\).
Сворачиваем правую часть по свойству суммы:
\(\log_5(7-x) = \log_5((3-x) \cdot 5)\).
\(7 - x = 15 - 5x\).
\(4x = 8 \implies x = 2\).
