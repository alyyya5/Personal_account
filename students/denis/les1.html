1
Линейные уравнения
Общий вид

\(ax + b = 0\), где \(a\) и \(b\) — числа, \(x\) — переменная.

\(ax = -b \quad \Rightarrow \quad x = -\dfrac{b}{a}\)
Количество корней
  • \(a \neq 0\) — ровно один корень.
  • \(a = 0\), \(b = 0\) — бесконечно много корней (любое число).
  • \(a = 0\), \(b \neq 0\) — корней нет.
2
Дробно-рациональные уравнения
Главное правило
Знаменатель не может быть равен нулю!

Прежде чем решать, находим ограничения — все значения \(x\), при которых знаменатели обращаются в нуль.

Если есть дробь \(\dfrac{A(x)}{B(x)}\), то \(B(x) \neq 0\)
Как решать
  • Шаг 1. Найти ограничения: \(x \neq \dots\)
  • Шаг 2. Найти общий знаменатель.
  • Шаг 3. Умножить обе части на общий знаменатель.
  • Шаг 4. Решить получившееся уравнение.
  • Шаг 5. Проверить корни по ограничениям.
  • Шаг 6. Записать ответ.
✅ Важно: корень, который не подходит по ограничению, — посторонний. Его нужно отбросить.
Особые случаи
  • Пропорция: \(\dfrac{a}{b} = \dfrac{c}{d} \Rightarrow ad = bc\)
  • Дробь = число: \(\dfrac{A(x)}{B(x)} = k \Rightarrow A(x) = k \cdot B(x)\)
  • Разность квадратов: \(x^2 - a^2 = (x - a)(x + a)\)
После умножения на общий знаменатель уравнение обычно становится линейным или квадратным.
3
Ловушки ограничений
Сокращение
Нельзя сокращать на выражение, которое может быть равно нулю!

Сначала находим ограничения, потом решаем, потом проверяем.

\(\dfrac{(x - a) \cdot A(x)}{x - a} = A(x)\) только если \(x \neq a\)
Посторонние корни
  • После решения всегда проверяй корни по ограничениям.
  • Корень, который даёт деление на нуль, — посторонний.
  • Если все корни посторонние — в ответе пишем «корней нет».
Когда корней нет
  • Уравнение привелось к противоречию: \(0 = 5\), \(-1 = 0\) и т.п.
  • Все найденные корни не прошли проверку по ограничениям.
  • В ответе: \(\varnothing\) или «корней нет».
📌
Алгоритм решения
Пошагово
  • 1. Найти ограничения — все \(x\), при которых знаменатели равны нулю.
  • 2. Записать: \(x \neq \dots\)
  • 3. Найти общий знаменатель.
  • 4. Умножить обе части на общий знаменатель.
  • 5. Решить получившееся уравнение.
  • 6. Проверить каждый корень по ограничениям.
  • 7. Записать ответ — только те корни, которые подходят.
✅ Запомни: проверка — это не «для галочки». Без неё можно легко ошибиться!
