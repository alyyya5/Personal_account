Ключевые принципы ЕГЭ

⚠️ Главное правило

В дробно-рациональных уравнениях всегда пиши ОДЗ первым действием.

\[ \frac{f(x)}{g(x)} = 0 \;\Rightarrow\; \begin{cases} f(x) = 0 \\ g(x) \neq 0 \end{cases} \]
💡 Потеря ОДЗ = потеря баллов на экзамене, даже если ответ правильный.

Линейные уравнения
Повторение

📖 Алгоритм

  1. Раскрыть скобки (если есть).
  2. Перенести слагаемые с \(x\) влево, без \(x\) — вправо (с противоположным знаком).
  3. Привести подобные и разделить на коэффициент при \(x\).
⚠️ Особые случаи: \(0\cdot x = 0\) — бесконечно много корней; \(0\cdot x = 5\) — корней нет.

Ответ:

Ответ:
Особый случай
\[ 5x - 3 = 5x + 2 \]
Ответ:
Пропорция
\[ \frac{2x - 3}{3} = \frac{x + 1}{2} \]
Ответ:

Дробно-рациональные уравнения
Не забудь ОДЗ!

📖 Алгоритм

  1. Записать ОДЗ: знаменатели ≠ 0.
  2. Привести к общему знаменателю или использовать пропорцию.
  3. Решить полученное уравнение.
  4. Проверить корни по ОДЗ.
Пример: \(\dfrac{2}{x-1} = \dfrac{3}{x+2}\)
ОДЗ: \(x \neq 1,\; x \neq -2\). Пропорция: \(2(x+2) = 3(x-1) \Rightarrow x = 7\). ✓
Простая пропорция
\[ \frac{5}{x + 2} = \frac{4}{x - 1} \]
Ответ:
Общий знаменатель
\[ \frac{1}{x} + \frac{1}{x + 1} = \frac{3}{2} \]
Ответ:
С квадратным знаменателем
\[ \frac{x + 2}{x - 1} = \frac{x + 3}{x + 1} \]
Ответ:
Дробь = число
\[ \frac{x + 1}{x - 2} = 3 \]
Ответ:
Сумма дробей
\[ \frac{x}{x - 2} - \frac{2}{x + 2} = \frac{8}{x^2 - 4} \]
Ответ:
Разность квадратов в знаменателе
\[ \frac{3}{x^2 - 9} = \frac{1}{x - 3} \]
Ответ:
4
Ловушки ОДЗ
Типичные ошибки ЕГЭ

⚠️ Три типа ловушек

  • Корень совпадает с запрещённым значением — ответ: «нет корней».
  • После сокращения исчезает знаменатель — нужно восстановить ОДЗ.
  • Радикалы в знаменателе — подкоренное выражение > 0 (строгое неравенство).
💡 Корень, который не входит в ОДЗ, не является решением.
Ловушка №1
\[ \frac{x^2 - 4x + 4}{x - 2} = 0 \]
Ответ:
Ловушка №2
\[ \frac{x^2 - 5x + 6}{x - 2} = 0 \]
Ответ:
Ловушка №3
\[ \frac{5}{x - 1} = \frac{3}{x - 1} + 2 \]
Ответ:
Радикал в знаменателе
\[ \sqrt{x - 2} = \frac{1}{\sqrt{x - 2}} \]
Ответ:
Дробь = число
\[ \frac{2x + 3}{x - 4} = 2 \]

Уравнения с модулем
Новая тема

📖 Определение модуля

Модуль \(|a|\) — расстояние от точки \(a\) до нуля. Всегда неотрицателен.

\[ |a| = \begin{cases} a, & \text{если } a \geq 0 \\ -a, & \text{если } a < 0 \end{cases} \]

✏️ Два главных типа уравнений

Тип 1: \(|f(x)| = a\), где \(a \geq 0\)
Раскрывается как два уравнения: \(f(x) = a\) и \(f(x) = -a\).
Пример: \(|x - 3| = 5 \;\Rightarrow\; x = 8\) или \(x = -2\)
Тип 2: \(|f(x)| = |g(x)|\)
Раскрывается как: \(f(x) = g(x)\) или \(f(x) = -g(x)\).
⚠️ Если \(|f(x)| = a\), где \(a < 0\) — корней нет!
Простой модуль
\[ |3x - 7| = 5 \]
Ответ:
Модуль = отрицательное число
\[ |2x + 1| = -3 \]
Ответ:
Два модуля
\[ |2x - 1| = |x + 4| \]
Ответ:
Модуль + число
\[ |x - 2| + 3 = 7 \]
Ответ:
Модуль с ОДЗ
\[ |x^2 - 4| = x - 2 \]
Ответ:
6
Уравнения с параметром
Знакомство с заданием №18

📖 Что такое параметр?

Параметр — буква (\(a, p, c\)), которая ведёт себя как число, но её значение неизвестно. Нужно исследовать, как меняется ответ в зависимости от параметра.

✏️ Алгоритм

  1. Решить уравнение «как обычно», считая параметр числом.
  2. Выделить особые случаи (когда коэффициент при \(x\) равен 0).
  3. Проанализировать каждый особый случай отдельно.
Пример: \((a - 3)x = a^2 - 9\)
Когда бесконечно много решений? Нужно: \(a - 3 = 0\) и \(a^2 - 9 = 0\).
Оба условия дают \(a = 3\). Проверка: \(0\cdot x = 0\) — любое \(x\) решение. ✓
Ответ: \(a = 3\).
