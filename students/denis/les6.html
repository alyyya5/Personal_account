Определение логарифма
1. Что такое логарифм
Определение
Логарифм числа \(b\) по основанию \(a\) — это показатель степени, в которую нужно возвести \(a\), чтобы получить \(b\).
\(\log_a b = c \;\Longleftrightarrow\; a^c = b\)
Примеры:
\(\log_2 8 = 3\), потому что \(2^3 = 8\)
\(\log_3 \dfrac{1}{9} = -2\), потому что \(3^{-2} = \dfrac{1}{9}\)
\(\log_5 1 = 0\), потому что \(5^0 = 1\)
⚠️ ОДЗ логарифма
  • Аргумент: \(b > 0\)
  • Основание: \(a > 0\), \(a \neq 1\)
⚙️
Основные свойства
2. Свойства логарифмов

Пусть \(a > 0\), \(a \neq 1\), \(b > 0\), \(c > 0\). Тогда:

2.1. \(\log_a (bc) = \log_a b + \log_a c\)
2.2. \(\log_a \dfrac{b}{c} = \log_a b - \log_a c\)
2.3. \(\log_a b^n = n \cdot \log_a b\)
2.4. \(\log_a a = 1\)
2.5. \(\log_a 1 = 0\)
Примеры:
\(\log_2 4 + \log_2 8 = \log_2 32 = 5\)
\(\log_3 54 - \log_3 2 = \log_3 27 = 3\)
\(\log_5 25^3 = 3 \cdot \log_5 25 = 3 \cdot 2 = 6\)
✅ Как читать

Логарифм произведения = сумма логарифмов.
Логарифм частного = разность логарифмов.
Степень можно вынести вперёд как множитель.

🔀
Переход к новому основанию
3. Формула перехода
\(\log_a b = \dfrac{\log_c b}{\log_c a}\)

Частный случай — когда основание является степенью:

\(\log_{a^k} b = \dfrac{1}{k} \cdot \log_a b\)
Примеры:
\(\log_4 8 = \dfrac{\log_2 8}{\log_2 4} = \dfrac{3}{2} = 1{,}5\)
\(\log_8 2 = \dfrac{1}{3} \cdot \log_2 2 = \dfrac{1}{3}\)
✅ Зачем это нужно

Когда основания разные — приводим их к одному, чаще всего к самому маленькому.

🔥
Основное тождество
4. Основное логарифмическое тождество
\(a^{\log_a b} = b\)

Если основание степени совпадает с основанием логарифма в показателе — они «сокращаются», и остаётся только аргумент.

Примеры:
\(2^{\log_2 7} = 7\)
\(3^{\log_3 4 + 1} = 3^{\log_3 4} \cdot 3 = 4 \cdot 3 = 12\)
\(5^{2\log_5 3} = 5^{\log_5 9} = 9\)
✅ Полезные следствия
\(a^{n \log_a b} = b^n \qquad \log_a a^k = k\)
🎯
Задания в формате ЕГЭ
5. Комбинированные задачи

В таких заданиях нужно использовать несколько свойств подряд.

⚠️ Стратегия решения
  1. Привести все логарифмы к одному основанию.
  2. Свернуть сумму или разность в один логарифм.
  3. Вынести степени, если они есть.
  4. Использовать определение или основное тождество.
Пример 1. \(\log_6 3 + \log_6 12\)
Сворачиваем в один логарифм: \(\log_6 (3 \cdot 12) = \log_6 36 = 2\).
Пример 2. \(\log_5 100 - \log_5 4\)
Разность логарифмов: \(\log_5 \dfrac{100}{4} = \log_5 25 = 2\).
Пример 3. \(3^{\log_3 4 + 2}\)
Разбиваем степень: \(3^{\log_3 4} \cdot 3^2 = 4 \cdot 9 = 36\).
✏️
Простейшие уравнения
6. Простейшие логарифмические уравнения
Определение
Логарифмическое уравнение — уравнение, в котором неизвестное стоит под знаком логарифма.
\(\log_a x = c \;\Longleftrightarrow\; x = a^c\),   при \(x > 0\)
⚠️ План решения
  1. Найти ОДЗ: под логарифмом — положительное число.
  2. Использовать определение: \(\log_a x = c \Rightarrow x = a^c\).
  3. Проверить корень по ОДЗ.
  4. Записать ответ.
Пример 1. \(\log_2 x = 5\).
ОДЗ: \(x > 0\). \(x = 2^5 = 32\). ✔
Ответ: \(32\).
Пример 2. \(\log_3 (x + 1) = 2\).
ОДЗ: \(x + 1 > 0 \Rightarrow x > -1\).
\(x + 1 = 3^2 = 9 \Rightarrow x = 8\). ✔
Ответ: \(8\).
Пример 3. \(\log_5 (2x - 3) = 1\).
ОДЗ: \(2x - 3 > 0 \Rightarrow x > 1{,}5\).
\(2x - 3 = 5 \Rightarrow x = 4\). ✔
Ответ: \(4\).
⚠️ Внимание

Под логарифмом всегда должно быть \(> 0\). Если при решении корень не проходит ОДЗ — его отбрасывают.
