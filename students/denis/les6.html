√ Теория · Иррациональные уравнения

Простые уравнения с квадратным и кубическим корнем
Алгебра Профиль
√
Основные понятия
1. Что такое иррациональное уравнение
Определение
Иррациональное уравнение — это уравнение, в котором переменная находится под знаком корня.

Мы будем решать простые уравнения двух видов:

\(\sqrt{A} = B \quad \text{и} \quad \sqrt{A} = \sqrt{B}\)

где \(A\) и \(B\) — выражения с переменной \(x\).

2. Свойства корня
⚠️ Главное свойство

Арифметический квадратный корень \(\sqrt{A}\) существует только тогда, когда подкоренное выражение неотрицательно:

\(\sqrt{A} \geq 0 \quad \text{и} \quad A \geq 0\)

То есть корень не может быть отрицательным, и под корнем не может быть отрицательного числа.

📌 Кубический корень

Кубический корень \(\sqrt[3]{A}\) существует при любом \(A\) — и положительном, и отрицательном, и нуле.

\(\sqrt[3]{8} = 2, \quad \sqrt[3]{-8} = -2, \quad \sqrt[3]{0} = 0\)
🔧
Методы решения
3. Уравнение вида \(\sqrt{A} = B\)
⚠️ Алгоритм решения
  1. Записать ограничение: \(A \geq 0\).
  2. Записать условие: \(B \geq 0\) (правая часть неотрицательна).
  3. Возвести обе части уравнения в квадрат: \(A = B^2\).
  4. Решить получившееся уравнение.
  5. Проверить корни по ограничениям (подставить).
  6. Отбросить посторонние корни.
✅ Пример

Решим уравнение \(\sqrt{6x + 3} = 9\):

  • Ограничение: \(6x + 3 \geq 0 \Rightarrow x \geq -0{,}5\)
  • Правая часть: \(9 \geq 0\) — верно
  • Возводим в квадрат: \(6x + 3 = 81\)
  • \(6x = 78 \Rightarrow x = 13\)
  • Проверка: \(13 \geq -0{,}5\) — подходит

Ответ: \(x = 13\).

4. Уравнение вида \(\sqrt{A} = \sqrt{B}\)
⚠️ Алгоритм решения
  1. Записать ограничения: \(A \geq 0\) и \(B \geq 0\).
  2. Возвести обе части уравнения в квадрат: \(A = B\).
  3. Решить получившееся уравнение.
  4. Проверить корни по ограничениям.
  5. Отбросить посторонние корни.
✅ Пример

Решим уравнение \(\sqrt{2x + 7} = \sqrt{x + 12}\):

  • Ограничения: \(2x + 7 \geq 0\) и \(x + 12 \geq 0\)
  • Возводим в квадрат: \(2x + 7 = x + 12\)
  • \(x = 5\)
  • Проверка: \(2 \cdot 5 + 7 = 17 \geq 0\), \(5 + 12 = 17 \geq 0\) — подходит

Ответ: \(x = 5\).

5. Уравнение вида \(\sqrt[3]{A} = B\)
⚠️ Алгоритм решения
  1. Возвести обе части уравнения в куб: \(A = B^3\).
  2. Решить получившееся уравнение.
  3. Проверить корни (подставить в исходное уравнение).

Ограничений нет — кубический корень существует при любом \(A\).

✅ Пример

Решим уравнение \(\sqrt[3]{2x - 5} = 3\):

  • Возводим в куб: \(2x - 5 = 27\)
  • \(2x = 32 \Rightarrow x = 16\)
  • Проверка: \(\sqrt[3]{2 \cdot 16 - 5} = \sqrt[3]{27} = 3\) — верно

Ответ: \(x = 16\).

⚠️
Особые случаи
6. Когда корней нет
⚠️ Случай 1: корень = отрицательное число

Уравнение \(\sqrt{A} = -5\) не имеет решений, потому что квадратный корень не может быть отрицательным.

\(\sqrt{A} \geq 0\), поэтому \(\sqrt{A} = -5\) — невозможно.
⚠️ Случай 2: под корнем отрицательное

Если при найденном \(x\) подкоренное выражение получается отрицательным — этот корень посторонний.

7. Посторонние корни
⚠️ Почему они появляются

При возведении в квадрат знак теряется:

\(x = -3 \quad \Rightarrow \quad x^2 = 9\) — но у \(x^2 = 9\) два корня: \(3\) и \(-3\).

Корень \(x = 3\) — посторонний для исходного уравнения.

✅ Как проверять
  • Подставь каждый корень в исходное уравнение.
  • Если равенство выполняется — корень подходит.
  • Если нет — отбрасываем.
  • Если все корни посторонние — в ответе «корней нет».
📌
Итоговый алгоритм
Пошаговая инструкция
  1. Определи вид уравнения: \(\sqrt{A} = B\), \(\sqrt{A} = \sqrt{B}\) или \(\sqrt[3]{A} = B\).
  2. Запиши ограничения (для квадратного корня: подкоренное \(\geq 0\), правая часть \(\geq 0\)).
  3. Возведи обе части в нужную степень (в квадрат или в куб).
  4. Реши получившееся уравнение.
  5. Проверь каждый корень по ограничениям.
  6. Отбрось посторонние корни.
  7. Запиши ответ.
✅ Запомни

Проверка корней — это обязательный шаг. Без неё ответ будет неверным.
