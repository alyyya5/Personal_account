§1 Что такое показательное уравнение

Определение. Показательным уравнением называется уравнение, в котором неизвестная переменная содержится в показателе степени.

Простейшее показательное уравнение имеет вид:

\(a^{f(x)} = a^{g(x)}, \quad a > 0, \quad a \neq 1\)
Ключевая идея: если основания степеней одинаковы (\(a > 0\), \(a \neq 1\)), то равенство степеней равносильно равенству показателей: \[a^{f(x)} = a^{g(x)} \quad \Leftrightarrow \quad f(x) = g(x)\]
Важно! Основание должно быть положительным и не равным 1. Иначе переход к равенству показателей может быть неверным.

§2 Свойства степеней, которые нужны для решения

Формула Пояснение
\(a^m \cdot a^n = a^{m+n}\) при умножении показатели складываются
\(\dfrac{a^m}{a^n} = a^{m-n}\) при делении показатели вычитаются
\((a^m)^n = a^{m \cdot n}\) степень в степени — показатели перемножаются
\(a^0 = 1\) любое число в нулевой степени равно 1
\(a^{-n} = \dfrac{1}{a^n}\) отрицательная степень — это дробь
\(a^{1/n} = \sqrt[n]{a}\) дробная степень — это корень
Совет: чтобы привести обе части уравнения к одинаковому основанию, полезно представлять числа как степени одного и того же числа. Например: \(4 = 2^2\), \(8 = 2^3\), \(9 = 3^2\), \(27 = 3^3\), \(\dfrac{1}{2} = 2^{-1}\).

§3 Алгоритм решения простейшего показательного уравнения

  1. Привести обе части уравнения к одинаковому основанию. Использовать свойства степеней.
  2. Приравнять показатели степеней. Получить обычное уравнение.
  3. Решить полученное уравнение. Найти \(x\).
  4. Проверить корень. Убедиться, что основание положительно и не равно 1.
Пример 1. Решить уравнение \(2^{x} = 8\).
Представим 8 как степень двойки: \(8 = 2^3\).
Получим: \(2^{x} = 2^3\).
Основания одинаковы, значит: \(x = 3\).
Ответ: \(3\).
Пример 2. Решить уравнение \(3^{2x - 1} = 27\).
\(27 = 3^3\).
\(3^{2x - 1} = 3^3\).
\(2x - 1 = 3\).
\(2x = 4\).
\(x = 2\).
Ответ: \(2\).
Пример 3. Решить уравнение \(5^{x + 2} = \dfrac{1}{25}\).
\(\dfrac{1}{25} = 5^{-2}\).
\(5^{x + 2} = 5^{-2}\).
\(x + 2 = -2\).
\(x = -4\).
Ответ: \(-4\).

§4 Что такое логарифм

Определение. Логарифмом числа \(b\) по основанию \(a\) называется показатель степени, в которую нужно возвести \(a\), чтобы получить \(b\).
\(\log_a b = c \quad \Leftrightarrow \quad a^c = b\)
Условия:
  • \(a > 0\), \(a \neq 1\) — основание;
  • \(b > 0\) — аргумент (логарифм существует только от положительного числа).
Основное логарифмическое тождество:
\(a^{\log_a b} = b\)
◆ СВОЙСТВА · ЛОГАРИФМЫ ◆

§5 Свойства логарифмов, которые нужны для решения

Формула Пояснение
\(\log_a (bc) = \log_a b + \log_a c\) логарифм произведения
\(\log_a \dfrac{b}{c} = \log_a b - \log_a c\) логарифм частного
\(\log_a b^n = n \log_a b\) степень выносится вперёд
\(\log_a a = 1\) логарифм основания равен 1
\(\log_a 1 = 0\) логарифм единицы равен 0
\(\log_a b = \dfrac{\log_c b}{\log_c a}\) переход к новому основанию
Совет: чтобы привести логарифмы к одинаковому основанию, полезно помнить: \(\log_2 4 = 2\), \(\log_3 9 = 2\), \(\log_2 8 = 3\), \(\log_5 25 = 2\), \(\log_{10} 100 = 2\).

§6 Алгоритм решения простейшего логарифмического уравнения

  1. Привести уравнение к виду \(\log_a f(x) = \log_a g(x)\). Использовать свойства логарифмов.
  2. Приравнять аргументы: \(f(x) = g(x)\).
  3. Решить полученное уравнение. Найти \(x\).
  4. Проверить ОДЗ: аргументы логарифмов должны быть положительными.
  5. Отбросить посторонние корни. Записать ответ.
Ключевая идея: если основания логарифмов одинаковы (\(a > 0\), \(a \neq 1\)), то равенство логарифмов равносильно равенству их аргументов при условии положительности аргументов: \[\log_a f(x) = \log_a g(x) \quad \Leftrightarrow \quad \begin{cases} f(x) = g(x) \\ f(x) > 0 \end{cases}\]
Пример 1. Решить уравнение \(\log_2 x = 3\).
По определению логарифма: \(x = 2^3 = 8\).
Проверка ОДЗ: \(x = 8 > 0\) — верно.
Ответ: \(8\).
Пример 2. Решить уравнение \(\log_3 (x + 1) = 2\).
По определению: \(x + 1 = 3^2 = 9\).
\(x = 8\).
Проверка ОДЗ: \(x + 1 = 9 > 0\) — верно.
Ответ: \(8\).
Пример 3. Решить уравнение \(\log_2 (x - 3) = \log_2 (2x - 7)\).
Основания одинаковы, приравниваем аргументы:
\(x - 3 = 2x - 7\)
\(x - 2x = -7 + 3\)
\(-x = -4\)
\(x = 4\).
Проверка ОДЗ: \(x - 3 = 1 > 0\), \(2x - 7 = 1 > 0\) — верно.
Ответ: \(4\).
Пример 4. Решить уравнение \(\log_5 (x - 2) = \log_5 (3x - 8)\).
\(x - 2 = 3x - 8\)
\(x - 3x = -8 + 2\)
\(-2x = -6\)
\(x = 3\).
Проверка ОДЗ: \(x - 2 = 1 > 0\), \(3x - 8 = 1 > 0\) — верно.
Ответ: \(3\).

§7 Что нужно уметь для задания №7

Типичные задания:
  • Решить показательное уравнение вида \(a^{f(x)} = a^{g(x)}\) и найти корень.
  • Решить логарифмическое уравнение вида \(\log_a f(x) = b\) или \(\log_a f(x) = \log_a g(x)\).
  • Найти корень уравнения, используя определение логарифма.
  • Применить свойства степеней или логарифмов для упрощения.
Что важно помнить:
  • Основание степени и логарифма должно быть \(> 0\) и \(\neq 1\).
  • Аргумент логарифма должен быть \(> 0\).
  • При решении логарифмических уравнений обязательна проверка ОДЗ.
  • В показательных уравнениях удобно приводить обе части к одному основанию.
Пример из ЕГЭ. Найдите корень уравнения \(2^{x - 7} = \dfrac{1}{8}\).
\(\dfrac{1}{8} = 2^{-3}\).
\(2^{x - 7} = 2^{-3}\).
\(x - 7 = -3\).
\(x = 4\).
Ответ: \(4\).
Пример из ЕГЭ. Найдите корень уравнения \(\log_4 (x + 3) = 2\).
По определению логарифма: \(x + 3 = 4^2 = 16\).
\(x = 13\).
Проверка ОДЗ: \(x + 3 = 16 > 0\) — верно.
Ответ: \(13\).
Пример из ЕГЭ. Найдите корень уравнения \(\log_3 (2x - 5) = \log_3 (x + 1)\).
\(2x - 5 = x + 1\)
\(2x - x = 1 + 5\)
\(x = 6\).
Проверка ОДЗ: \(2x - 5 = 7 > 0\), \(x + 1 = 7 > 0\) — верно.
Ответ: \(6\).
